# mekomikudo

看護学生・新人看護師の学習を支えるWebサイトです。

検査値、薬剤、看護技術、疾患・病態などを、確認しやすい形で整理しています。

## Webサイト

[mekomikudo.jp](https://mekomikudo.jp/)

## 掲載内容

- 検査値一覧
- 薬剤一覧・薬剤比較
- 看護技術・疾患の学習ノート

## 技術構成

HTML、CSS、JavaScriptで構成し、GitHub Pagesで公開しています。

## 注意事項

掲載情報は学習目的です。実際の医療行為や判断では、最新の電子添文、所属施設の基準、医療従事者の指示を優先してください。
