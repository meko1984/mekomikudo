陰部洗浄

  • 「洗う」だけで終わらない。
  • 羞恥心を守り、汚れを広げず、皮膚を傷つけずに洗う。
  • 異常を見つける。
学習用
優先する条件・指示・手順
  • 患者の状態
  • セルフケア能力
  • 手術の有無
  • 創傷の有無
  • 皮膚疾患の有無
  • 採用製品の表示
  • 院内手順
  • 上記の条件・指示・手順を優先する。

注意事項

始める前に止まって確認
  • 開始前に確認する状態
    • 外陰部の手術直後
    • 会陰部の手術直後
    • 出血
    • 深い創
    • 強い疼痛
  • 洗浄方法や体位に個別の制限がある
  • アレルギー歴を確認する製品
    • 洗浄剤
    • 保湿剤
    • 皮膚保護剤
    • 粘着剤
    • アレルギー歴があれば、開始前に使用の可否を確認する。
  • 本人が拒否している、または十分な説明ができていない
できる部分は本人に任せる
  • 手順を一方的に進めない。
  • 本人の希望
    • 呼び方
    • 介助者
    • 体位
    • 露出範囲

    希望を確認して、セルフケアを支える。

目的

  • やさしく除去する汚れ
    • 尿
    • 便
    • 汗
    • 分泌物
  • 軽減する症状
    • 不快感
    • 臭気
    • かゆみ
  • 早期に見つける変化
    • 発赤
    • びらん
    • 浸軟
    • 腫脹
    • 疼痛
  • 失禁関連皮膚炎（IAD）などの皮膚障害を予防する
  • 本人の尊厳と安楽を守る

観察項目

洗う前・洗いながら・洗った後を見る

  • 皮膚
    • 発赤
    • 浸軟
    • びらん
    • 亀裂
    • 圧迫痕
    • 発疹
  • 粘膜
    • 腫脹
    • 出血
    • 分泌物
    • 臭気
  • 症状
    • 疼痛
    • かゆみ
    • 灼熱感
    • 違和感
  • 排泄
    • 尿の量
    • 便の量
    • 尿の性状
    • 便の性状
    • 失禁の頻度
  • 留置物・創部の状態
    • カテーテル
    • ドレーン
    • 創部
    • 固定部
  • 皮膚所見の記録
    • 赤みの形
    • 左右差
    • 境界
    • 湿潤範囲
  • 鑑別が必要な皮膚障害の例
    • IAD
    • 真菌による皮膚障害
    • 接触皮膚炎
    • 褥瘡

    原因を見た目だけで決めつけない。

必要物品

  • 洗浄用ボトル
  • 患者に合う温度の湯
  • 施設採用の洗浄剤
  • ガーゼまたはやわらかい清拭材
  • 防水シート
  • 乾いたタオル
  • 非滅菌手袋
  • エプロン
  • 飛散リスクに応じたマスク
  • 飛散リスクに応じた眼の防護具
  • 廃棄物袋
  • 交換用の下着またはパッド
  • 必要時、交換用おむつ
  • 必要時、皮膚保護剤または保湿剤
  • 必要時、体位保持用クッション
  • おむつ・パッドの選択
    • 体格
    • 排泄量
    • 活動性
    • 皮膚状態

    特定の番号で固定せず、これらに合う製品を選ぶ。

  • 洗浄剤や皮膚保護剤は使用方法と洗い流しの要否を製品表示で確認する。

手順

洗浄する部位の位置関係

  1. 説明し、希望とセルフケア能力を確認
    開始前
    • 本人確認
    • 目的の説明
    • 方法の説明
    • 体位の説明
    • カーテンやドアを閉める。
    • 必要な部位だけ露出する。
  2. 物品・体位・湯温を整える
    • 防水シートを敷く。
    • 体位を整える際の確認
      • 呼吸
      • 疼痛
      • 関節可動域

      仰臥位や側臥位など、無理のない体位に整える。

    • 湯は陰部にかける前に本人と確認する。
  3. 強い汚れを先に取り除く
    • 手指衛生後にPPEを装着。
    • 便などは、皮膚をこすらず、押さえるように除去する。
    • 汚れた面を使い回さない。
  4. 女性：前から後ろへ、肛門は最後
    • 必要に応じて陰唇を開き、尿道口周囲から外側へ一方向に洗う。
    • 鼠径部を洗い、肛門は最後。
    • 膣内へ湯や洗浄剤を入れない。
  5. 男性：尿道口から外へ、包皮は戻す
    • 陰茎を支え、尿道口周囲から外へ。
    • 洗浄する部位
      • 亀頭
      • 陰茎
      • 陰嚢
      • 鼠径部
      • 尿道口から外へ洗う。
      • 肛門は最後に洗う。
    • 包皮を反転した場合は洗浄後に元へ戻す。
  6. 十分にすすぎ、押さえて乾かす
    • 洗い流す製品は残らないようすすぐ。
    • しわや皮膚が重なる部分も確認し、乾いたタオルでこすらず押さえる。
  7. 皮膚を守り、環境を戻す
    • 必要時は皮膚保護剤を製品表示どおりに使用。
    • 終了時に整えるもの
      • 下着
      • パッド
      • おむつ
      • 衣類
      • 寝具
      • 体位
    • PPEを外して手指衛生し、観察と実施内容を記録する。
順番の合言葉
  • 尿道口側から外へ洗い、肛門は最後にする。
  • ひと拭きごとに清潔な面へ替え、汚れを戻さない。

方法を個別化する

  • 個別化のための確認
    • 外陰部の形態
    • 手術歴
    • 性自認や羞恥心への配慮
    • 本人が望む呼び方
    • 本人が望む介助者
    • 本人が望む介助方法
  • 体位に配慮する状態
    • 拘縮
    • 疼痛
    • 呼吸困難
    • これらがある場合は、開脚や仰臥位を無理に続けない。
  • 個別のケア計画が必要な状態
    • 創傷
    • 皮膚疾患
    • 放射線治療部位
    • ストーマ

    これらがある場合は、個別のケア計画に従う。

  • 毎回石けんで何度も洗うのではなく、汚染量と皮膚状態に合わせる
  • 洗い流さない清拭料を使う場合は、水洗い用の手順と混同しない

膀胱留置カテーテルがある場合

洗浄のために回路を外さない

  • カテーテルを引っ張らず、尿道口周囲と皮膚を通常の衛生ケアで清潔にする
  • 接続部を外さず、チューブの屈曲と牽引を防ぐ
  • 採尿バッグは膀胱より低く保ち、床に置かない
  • 固定具の観察
    • 汚染
    • 浮き
    • 皮膚障害
    • 牽引
  • 固定具を毎回交換するとは限らない。
  • 固定具の交換で確認すること
    • 交換時期
    • 剥離剤
    • 貼付部位

    製品と院内手順に従う。

  • 洗浄を中止して報告する状態
    • カテーテルが抜けている
    • カテーテルの位置変化
    • 出血
    • 強い痛み

    これらがあれば、洗浄を続けず報告する。

失禁関連皮膚炎（IAD）を防ぐ

「洗いすぎ」と「こすりすぎ」も刺激になる

  • 尿・便と湿気で皮膚がふやける。
  • ふやけた皮膚へ摩擦が加わると、バリア機能が低下する。
  • 排泄物を長時間皮膚に触れさせない
  • 弱い力で洗い、押さえて水分を取る
  • 必要時は皮膚保護剤で排泄物との接触を減らす
  • 失禁ケアの見直し
    • 失禁の原因
    • パッドの吸収量
    • 交換間隔

報告・記録

すぐに報告する変化

  • 出血・痛み・腫脹
    • 新しい出血
    • 強い疼痛
    • 急な腫脹
  • 皮膚の変化
    • 広がる発赤
    • びらん
    • 水疱
    • 皮膚欠損
  • 感染を疑う変化
    • 膿性分泌物
    • 強い悪臭
    • 発熱
  • カテーテル・尿の変化
    • カテーテルの抜去
    • カテーテルの位置変化
    • 尿流停止
    • 血尿
  • 本人の状態悪化や、ケアを続けられない苦痛

記録すること

  • 実施内容
    • 実施時刻
    • 方法
    • 使用した洗浄剤
    • 使用した皮膚保護剤
  • 観察の記録
    • 皮膚
    • 粘膜
    • 排泄物
    • 疼痛
  • 本人の反応とセルフケアの範囲
  • 報告内容と、その後の対応
