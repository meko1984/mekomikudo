中心静脈カテーテル（CVC）

  • 成人の非トンネル型CVCを中心に扱う。
処置別に確認する内容
  • 観察
  • 測定
  • 日常管理
  • 挿入介助
  • 抜去
学習用
優先する指示・手順
  • カテーテルの電子添文
  • 接続器具の電子添文
  • 院内手順
  • 医師の指示
  • 感染管理部門の指示
  • 実際の管理では、上記の指示・手順を優先する。

注意事項

感染・接続
  • アクセス前後に手指衛生
  • 接続部を規定の消毒薬・時間で消毒
  • 開放時間を最小限にする
  • 接続の確認
    • 緩み
    • 亀裂
    • 漏れ
    • 血液逆流
  • ルート開放時はクランプ忘れに注意
異常時
  • 感染・局所の異常
    • 発赤
    • 腫脹
    • 熱感
    • 疼痛
    • 排膿
    • 原因不明の発熱
  • 呼吸・循環の異常
    • 呼吸困難
    • 胸痛
    • SpO2低下
    • 急な血圧低下
  • 注入・開存性の異常
    • 注入時痛
    • 抵抗
    • 滴下不良
    • 逆血不良
  • 位置・デバイスの異常
    • 固定位置の変化
    • 事故抜去
    • カテーテル損傷
  • 異常時は使用を中止し、クランプ・安全確保後に報告
色だけでルーメンを判断しない
  • 製品ごとに異なる項目
    • 色
    • 太さ
    • 先端位置
    • 充填量
  • 確認する情報
    • カテーテル表示
    • 電子添文
    • ルートラベル

目的

  • 高浸透圧輸液・中心静脈栄養の投与
  • 血管刺激性の強い薬剤・昇圧薬などの投与
  • 安定した静脈路の確保
  • 血液採取
  • 中心静脈圧（CVP）の測定

観察項目

  • 必要性の評価
    • 留置目的
    • 使用中のルーメン
    • 不要となった可能性
  • 全身の観察
    • 体温
    • 悪寒
    • 呼吸
    • 循環
    • 意識
    • 疼痛
  • 挿入部の観察
    • 発赤
    • 腫脹
    • 熱感
    • 疼痛
    • 出血
    • 排膿
    • 浸出液
    • 皮膚障害
  • 固定の観察
    • 挿入長
    • 縫合・固定具
    • ドレッシング材の浮き・汚染・破損
  • ルートの観察
    • 接続
    • クランプ
    • 屈曲
    • 亀裂
    • 漏れ
    • 血液逆流
    • 気泡
    • ラベル
  • 開存性の観察
    • 滴下・注入状態
    • 注入時痛
    • 抵抗
    • 逆血の状態
  • 血栓・位置異常の観察
    • 頸部・上肢の腫脹
    • 左右差
    • 疼痛
    • 挿入長の変化
  • CVPの評価
    • 波形
    • 体位
    • 呼吸条件
    • 経時変化

    値だけで判断しない。

必要性は毎日評価
  • 不要なCVCは感染リスクを増やす。
  • 抜去の可否をチームで確認する。

CVP測定

必要物品

  • CVP測定用ルーメン
  • 圧トランスデューサー付きモニタリングキット
  • 指示されたフラッシュ液
  • 加圧バッグ
  • 生体情報モニター
  • 接続ケーブル
  • 水平器またはレベリング器具
  • 接続部用消毒薬
  • 手袋

手順

  1. 指示・測定条件を確認
    確認する項目
    • 測定目的
    • 単位
    • 体位
    • 人工呼吸器設定
    • 測定ルーメン
  2. 測定系を確認
    確認する項目
    • 接続の緩み
    • 屈曲
    • 閉塞
    • 血液逆流
    • 気泡
    • フラッシュ液
  3. 体位を整える
    • 原則として仰臥位。
    • 経時比較では同じ体位と呼吸条件へそろえる。
  4. 基準点へ高さを合わせる
    • トランスデューサーの大気開放点を右心房の高さに合わせる。
    • 目安は第4肋間・中腋窩線。
  5. 大気開放する
    • 患者側を閉じ、大気側を開く。
    • 活栓の向きを指差し確認。
  6. ゼロ校正する
    • モニターでゼロ校正。
    • ゼロ完了表示を確認。
  7. 患者側へ開放する
    • 大気側を閉じ、患者側を開く。
    • 生理的なCVP波形を確認。
  8. 値を読む
    • 呼気終末の値を確認。
    • 値を読む際に影響を除く条件
      • 咳
      • 体動
      • 会話
      • 胸腔内圧
  9. 測定系を復帰する
    • 指示どおり戻す対象
      • 三方活栓
      • クランプ
      • 輸液
    • 漏れと気泡を再確認。
  10. 記録する
    記録する項目
    • 値
    • 単位
    • 体位
    • 呼吸条件
    • 時刻
    • 波形
    • 関連所見
単一の値で循環血液量を決めない
CVPと合わせて評価する情報
  • 血圧
  • 尿量
  • 末梢循環
  • 呼吸状態
  • 超音波所見
  • 経時変化

CVCヘパリンロック

必要物品

  • 指示されたロック用ヘパリン製剤
  • 接続部用消毒薬
  • 手袋
  • 必要時、フラッシュ用生理食塩液
  • 廃棄物容器
このページで扱う製剤
  • ヘパリンNaロック用100単位/mLシリンジ10mL
  • 1シリンジ中1000単位
必要量の算出で合計する量
  • 使用ルーメンのプライミング量
  • 接続器具のプライミング量
  • 名称に注意：10単位/mL・10mL製剤は総量100単位。
  • 100単位/mL・10mL製剤は総量1000単位。
  • ロック時間：100単位/mL製剤の電子添文では12時間までを標準、最長24時間。
  • 継続時は指示と院内手順を確認。
製品例：Arrow AK-15703系・7Fr・トリプルルーメン・20cm
  • 茶・ディスタル（16G）：約0.47mL
  • 青・メディアル（18G）：約0.40mL
  • 白・プロキシマル（18G）：約0.42mL
  • 同系統のTeleflex公開資料による概算値。
  • 付属品を含まない。
  • 型番・世代により値が異なるため、実物の包装表示・電子添文を優先する。

手順

  1. 指示と製剤を確認
    確認する項目
    • 患者
    • ルーメン
    • 濃度
    • 使用目的
    • アレルギー
    • 出血
    • HIT歴
  2. 必要量を算出
    • カテーテルと接続器具の電子添文から内腔量を確認。
    • 合計量を算出。
  3. 接続部を消毒
    • 規定の方法と時間で消毒。
    • 十分に乾燥。
  4. 開存性を確認
    • 院内手順とデバイス仕様に沿って確認。
    • 抵抗があれば無理に注入しない。
  5. ロック液を注入
    • 算出量を注入。
    • デバイス指定の陽圧操作・クランプ順序を守る。
  6. 終了・記録
    • 接続とクランプを確認。
    • 記録する項目
      • 製剤
      • 濃度
      • 使用量
      • 時刻
    • 残液は再使用しない。
現物の製品名・型番を確認
  • 同じ20cmトリプルでも製品や付属品でプライミング量が異なる。
  • 上記は代表例。
  • 自分でも確認する情報
    • 包装表示
    • 製品資料
    • カテーテルの型番
    • 接続器具の型番
  • 10mL全量を一律に注入しない。

消毒・CHGドレッシング材交換

必要物品

  • CHG含有ドレッシング材
  • 規定の皮膚消毒薬
  • 滅菌手袋
  • 未滅菌手袋
  • マスク
  • 滅菌ガーゼ
  • 必要時、固定用具
  • 必要時、皮膚被膜剤
  • 必要時、剥離剤
  • 日付ラベル
  • 廃棄物容器

手順

  1. 適応と皮膚を確認
    確認する項目
    • CHG過敏症
    • 発赤
    • びらん
    • 出血
    • 浸出液
    • 固定位置
  2. 説明・体位調整
    • 挿入部を観察しやすい体位へ調整。
    • カテーテルを牽引しない。
  3. 古いドレッシング材を外す
    • カテーテルと皮膚を押さえる。
    • 押さえながら、端を折り返すようにゆっくり剥がす。
  4. 挿入部を観察
    確認する項目
    • 発赤
    • 熱感
    • 疼痛
    • 腫脹
    • 異臭
    • 排膿
    • 浸出液
    • 挿入長
  5. 手指衛生・無菌操作

    手指衛生後、院内手順に沿って無菌操作へ移行。

  6. 消毒・乾燥
    • 規定の消毒薬と接触時間で処置。
    • 薬液を完全に乾燥。
  7. ゲルパッドを合わせる
    • CHGゲルパッド中央を挿入部へ合わせる。
    • カテーテル周囲から密着。
  8. フィルムを貼付・固定
    • 伸ばさず貼付。
    • 中央から端へ押さえ、観察を妨げない位置へラベルを貼付。
  9. 記録
    記録する項目
    • 挿入部
    • 固定
    • 交換日
    • 皮膚状態
    • 異常の有無
施設手順と製品添付文書を優先
  • CHG含有製品は過敏症歴を確認。
  • CHG含有製品を使用しない対象
    • 感染部位
    • 生後2か月未満
    • 熱傷・粘膜
  • 成人の短期CVCで透明ドレッシング材に問題がなければ7日ごとの交換が目安。
  • 早めに交換する条件
    • 緩み
    • 汚染
    • 湿潤
    • 破損
    • 観察不能

    いずれかがあれば早めに交換。

CVルート交換

必要物品

  • 新しい輸液
  • 新しい輸液セット
  • 必要時、フィルター
  • 必要時、延長チューブ
  • 必要時、閉鎖式コネクタ
  • 接続部用消毒薬
  • 手袋
  • 廃棄物容器
  • 必要時、輸液ポンプ
  • ルートラベル

手順

  1. 指示と交換対象を確認
    確認する項目
    • 輸液
    • 投与速度
    • ルーメン
    • 配合変化
    • フィルター
    • 交換時期
  2. 新しいルートを組む
    • 清潔操作で接続。
    • 輸液を満たし、気泡を除去。
    • 末端を汚染しない。
  3. 患者側を止める
    • 輸液ポンプを停止。
    • 対象ルーメンをクランプ。
    • ほかのルートとの取り違えを防ぐ。
  4. 接続部を交換する
    • 旧ルートを外す。
    • 接続部を規定どおり消毒・乾燥し、新ルートを接続。
  5. 投与を再開する
    • クランプを開放。
    • 設定を照合し、滴下・ポンプ・接続部を確認。
  6. 全ルートをたどる
    • バッグから患者まで確認。
    • 全ルートをたどって確認する項目
      • 屈曲
      • 漏れ
      • 気泡
      • 誤接続
      • 不要な三方活栓
  7. 記録する
    記録する項目
    • 交換日時
    • 輸液
    • ルート
    • フィルター
    • 投与状態
交換間隔の目安
  • 一般の持続輸液：96時間以上の間隔をあけ、7日以内に交換
  • 血液・血液製剤・脂肪乳剤：投与開始から24時間以内
  • プロポフォール：バイアル交換時。製品指示に従い6時間または12時間ごと
  • CDCの感染対策上の目安。
  • 交換条件で優先する情報
    • 投与薬剤の電子添文
    • 輸液セットの仕様
    • 院内手順

CVPルート交換

必要物品

  • 圧トランスデューサー付きモニタリングキット
  • 指示されたフラッシュ液
  • 加圧バッグ
  • 接続ケーブル
  • 固定板
  • 水平器またはレベリング器具
  • 接続部用消毒薬
  • 手袋
  • 交換日ラベル

手順

  1. 指示とシステムを確認
    確認する項目
    • フラッシュ液
    • 交換対象
    • 加圧条件
    • 測定ルーメン
    • デバイス仕様
  2. 新しい測定系を接続
    清潔操作で接続する対象
    • フラッシュ液
    • モニタリングキット
    • トランスデューサー
  3. 回路内を満たす
    • バッグ側から末端まで順に満たす。
    • 気泡を残さない。
  4. 加圧・固定する
    • 製品指定の圧へ設定。
    • トランスデューサーを固定板へ取り付ける。
  5. 患者側をクランプする
    • 測定ルーメンを確認。
    • 旧回路を止め、開放時間を最小限にする。
  6. 新しい回路へ交換する
    • 接続部を消毒・乾燥。
    • 無菌的に新回路を接続し、閉鎖系を保つ。
  7. ゼロ校正する
    • 右心房の高さへ合わせ、大気開放してゼロ校正。
    • 患者側へ戻す。
  8. 波形と回路を確認
    確認する項目
    • CVP波形
    • 値
    • 気泡
    • 漏れ
    • 屈曲
    • 接続
    • 加圧バッグ
  9. 記録する
    記録する項目
    • 交換日時
    • フラッシュ液
    • 回路
    • ゼロ校正
    • CVP値と測定条件
ヘパリン加生理食塩液を一律に作らない
  • フラッシュ液の種類・濃度・交換間隔を決める情報
    • 医師指示
    • 院内手順
    • 測定キットの添付文書
  • 自己判断で混注しない。

挿入介助

必要物品

  • 予定したCVC挿入セット
  • 帽子
  • マスク
  • 滅菌ガウン
  • 滅菌手袋
  • 全身を覆う滅菌ドレープ
  • 超音波装置
  • 滅菌プローブカバー
  • 滅菌超音波ゲル
  • 局所麻酔薬
  • 規定の皮膚消毒薬
  • 滅菌生理食塩液
  • シリンジ
  • 注射針
  • 閉鎖式コネクタ
  • 固定具
  • 滅菌ドレッシング材
  • 生体情報モニター
  • 酸素投与物品
  • 救急対応物品
  • 鋭利物容器
  • 廃棄物容器

手順

  1. 指示・同意・患者を確認
    確認する項目
    • 適応
    • 穿刺部位
    • デバイス
    • ルーメン数
    • 説明・同意
    • アレルギー
  2. 出血・感染リスクを確認
    確認する項目
    • 凝固
    • 血小板
    • 抗血栓薬
    • 穿刺部位の感染
    • 既存デバイス
  3. モニター・体位を準備
    • 準備するモニター
      • 心電図
      • 血圧
      • SpO2
    • 緊急時に対応できる環境を確保。
  4. タイムアウトする
    共有する項目
    • 患者
    • 部位
    • 左右
    • デバイス
    • 役割分担
    • 緊急時対応
  5. 最大無菌バリアを準備
    準備する項目
    • 帽子
    • マスク
    • 滅菌ガウン
    • 滅菌手袋
    • 全身用滅菌ドレープ
  6. プレスキャンを確認
    共有する項目
    • 標的静脈
    • 深さ
    • 虚脱
    • 動脈・神経・肺との位置関係
    • 穿刺経路
  7. 無菌操作を介助
    • 介助する内容
      • 超音波
      • 消毒
      • 器具展開
      • 局所麻酔
    • 清潔・不潔の境界を維持。
  8. ガイドワイヤーを確認
    • 短軸像と長軸像で静脈内を確認。
    • 抵抗時は進めない。
    • 抜去後は遺残がないことを確認。
  9. ダイレーター操作を見守る
    • 過度な力や深い挿入を避ける。
    • 異常時は声をかけ、手技を止める。
  10. 留置後を確認
    照合する項目
    • 各ルーメン
    • 固定
    • 挿入長
    • 先端位置の確認方法
  11. 合併症を観察
    • 確認する項目
      • 呼吸
      • 循環
      • 胸痛
      • 出血
      • 血腫
      • 不整脈
      • 神経症状
    • 使用直後から数日以内の呼吸・循環異常では輸液を中止し、位置異常を疑って報告。
  12. 記録する
    記録する項目
    • 穿刺部位
    • デバイス
    • 挿入長
    • ルーメン
    • 固定
    • 観察所見
異常時は安易に抜去しない
  • 動脈内誤留置や静脈外迷入が疑われる場合は、個人判断で抜去しない。
  • 画像評価とチーム対応へつなぐ。

CVC抜去

必要物品

  • 未滅菌手袋
  • 滅菌手袋
  • マスク
  • 規定の皮膚消毒薬
  • 抜糸器具
  • 滅菌ガーゼ
  • 気密性の高い被覆材
  • 必要時、検体容器
  • 鋭利物容器
  • 廃棄物容器

手順

  1. 指示・患者・カテーテルを確認
    確認する項目
    • 抜去理由
    • 部位
    • 挿入長
    • 出血リスク
    • 培養指示
    • 実施者の権限
  2. 輸液を停止・クランプする
    • 全ルーメンを確認。
    • 輸液とポンプを停止し、カテーテルを閉鎖。
  3. 体位を整える
    • 内頸・鎖骨下静脈では仰臥位。
    • 可能なら下肢挙上または頭低位で静脈圧を保つ。
    • 禁忌や呼吸状態を確認。
  4. ドレッシング材と固定を外す
    • 挿入部を観察。
    • 無菌操作で消毒し、固定具または縫合糸を解除。
  5. 呼吸法を共有する
    • 咳・深吸気・会話を避ける。
    • 息こらえなど、施設手順と患者状態に合う方法を実施者と確認。
  6. カテーテルを抜去する
    • 実施者が抵抗を確認しながら滑らかに抜去。
    • 抵抗があれば中止。
  7. 圧迫・密閉する
    • 止血を確認。
    • 空気流入を防ぐ気密性の高い被覆材で確実に密閉。
  8. カテーテルを確認する
    • 先端を含め完全性を確認。
    • 破損・欠損があれば直ちに報告。
  9. 抜去後を観察する
    抜去後の観察
    • 呼吸困難
    • 胸痛
    • SpO2低下
    • 意識変化
    • 出血
    • 血腫
  10. 記録する
    記録する項目
    • 抜去日時
    • 部位
    • カテーテルの完全性
    • 止血
    • 被覆
    • 患者状態
抜去後も空気塞栓に注意
  • 抜去孔が閉鎖するまで静脈と体外が交通する可能性がある。
  • 被覆材の密閉と患者状態を確認。

関連知識

CVCと関連デバイス

  • 上半身から挿入する場合の経路を簡略化した模式図。
  • 赤い点は上大静脈下部〜上大静脈・右心房接合部付近の先端位置を示す。

主な合併症

CLABSI・局所感染
観察する徴候
  • 発熱
  • 悪寒
  • 発赤
  • 疼痛
  • 排膿

無菌操作と不要時の早期抜去が重要。

気胸・血胸
徴候の例
  • 呼吸困難
  • 胸痛
  • SpO2低下
  • 呼吸音左右差
動脈誤穿刺・血腫
徴候の例
  • 出血
  • 腫脹
  • 疼痛
  • 循環変動
空気塞栓
徴候の例
  • 急な呼吸困難
  • 胸痛
  • 低酸素
  • 血圧低下
  • 意識変容
不整脈
  • ガイドワイヤー・カテーテル先端による刺激。
  • 心電図変化を観察。
血栓・閉塞
徴候の例
  • 逆血不良
  • 注入抵抗
  • 上肢・頸部の腫脹
  • 疼痛
位置異常・損傷・事故抜去
徴候の例
  • 挿入長の変化
  • 滴下不良
  • 漏れ
  • 亀裂
  • 固定不良

ルーメンとカテーテル先端

  • Arrowの上記代表例
    • 茶＝ディスタル
    • 青＝メディアル
    • 白＝プロキシマル
  • 製品ごとに異なるルーメンの情報
    • 色
    • 太さ
    • 先端開口部
    • 充填量
  • 色だけでCVP用・輸液用などの用途を決めない
  • 照合する情報
    • カテーテル表示
    • 電子添文
    • ルートラベル
  • 先端は上大静脈下部〜上大静脈・右心房接合部付近が目安
  • 逆血のみで先端位置や静脈内留置を断定しない
