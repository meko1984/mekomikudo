輸血

  • バッグより先に患者を見る。
  • 照合で取り違えを防ぐ。
  • 開始直後の小さな変化から副反応を見つける。
学習用
個別に確認する事項
  • 製剤の選択
  • 適合試験
  • 投与量
  • 投与速度
  • ルート
  • 加温
  • 前投薬
  • 副反応時の検査
  • 副反応時の治療
優先する指示・条件・手順
  • 医師の指示
  • 輸血部門
  • 電子添文
  • 採用製品
  • 院内手順
  • 個別に確認する事項は、上記の指示・条件・手順を優先する。

注意事項

一致しなければ開始しない
  • 一致を確認する対象
    • 患者
    • 指示
    • 適合票
    • 製剤本体
    • 電子照合

    どれかが一致しなければ開始しない。

  • 疑問があれば開始しない項目の例
    • 製剤名
    • 血液型
    • 製造番号
    • 有効期限
    • 適合試験
  • 使用しない外観異常の例
    • バッグの破損
    • 漏れ
    • 変色
    • 凝固
    • 著しい凝集
  • 開始しない体制上の問題
    • 輸血前の状態を確認できない
    • 緊急連絡先が整っていない
    • 観察体制が整っていない
副反応を疑ったら直ちに輸血を止める
  • 呼吸の変化
    • 呼吸困難
    • 喘鳴
    • SpO₂低下
    • チアノーゼ
  • 循環・意識・疼痛の変化
    • 血圧低下
    • 意識変化
    • 胸痛
    • 腰背部痛
    • 動悸
  • 全身の変化・訴え
    • 発熱
    • 悪寒
    • 戦慄
    • 熱感
    • 強い不安や「何かおかしい」という訴え
  • 皮膚・粘膜の変化
    • 蕁麻疹
    • 発疹
    • 掻痒
    • 顔面の腫脹
    • 口唇の腫脹
  • その他の変化
    • 悪心
    • 嘔吐
    • 赤褐色尿
    • 出血傾向
    • 点滴部痛
自己判断で再開しない
  • 軽い発疹に見えても重症化することがある。
  • 輸血を止める。
  • 患者を評価する。
  • 応援を呼び、医師と輸血部門へ連絡する。
  • 指示と手順で決める事項
    • 再開
    • 薬剤
    • 検体
    • 製剤返却

何を補う輸血か

  • 赤血球製剤：赤血球を補い、酸素運搬能を改善する
  • 血小板製剤：血小板を補い、一次止血を支える
  • 新鮮凍結血漿（FFP）：複数の凝固因子を補う
  • アルブミン製剤：血漿分画製剤。輸血用血液製剤とは管理・適応が異なる
  • 輸血は補充療法。
  • 原因治療の代わりにはならない。
  • 製品ごとに異なる項目
    • 製剤の種類
    • 単位数
    • 容量

    製品表示と指示で確認する。

輸血前の検査と準備

検査名より、どの安全を確かめるか

  • ABO・RhD血液型：患者の血液型を確認する
  • 不規則抗体検査：臨床的に重要な赤血球抗体を調べる
  • 交差適合試験：患者血液と赤血球製剤の適合性を確認する
  • T&S・コンピュータクロスマッチ：条件を満たす場合に用いる準備・照合方法
  • 検体採取時から患者を確実に識別し、採血後にベッドサイドで表示する
  • 確認する患者歴
    • 輸血歴
    • 妊娠歴
    • 既往抗体
    • 過去の副反応
  • 検体の有効期間や再採血条件は患者歴と院内手順で変わる
  • 血小板・FFPを含め、必要な検査と適合基準は製剤・状況で異なる

開始前の観察

輸血前の基準をつくる

  • バイタルの確認
    • 体温
    • 血圧
    • 脈拍
    • 呼吸数
    • 可能ならSpO₂
  • 意識・呼吸・症状の確認
    • 意識
    • 顔色
    • 呼吸音
    • 呼吸困難
    • 胸痛
    • 悪寒
    • 疼痛
  • 皮膚・体液状態の確認
    • 発疹
    • 掻痒
    • 浮腫
    • 頸静脈怒張
    • 体重
    • 尿量
  • 静脈路の確認
    • 逆血
    • 滴下
    • 疼痛
    • 腫脹
    • 漏れ
    • 固定
  • 患者リスクの確認
    • 心不全
    • 腎機能低下
    • 体液過剰
    • 重いアレルギー
開始前からある症状の例
  • 発熱
  • 発疹
  • 呼吸困難
  • すでにある症状は、開始後の変化と区別できるよう記録する。
  • 症状がある場合は、開始してよいか確認する。

必要物品

  • 末梢静脈カテーテルのゲージを一律に決めない
  • カテーテルを選ぶ基準
    • 患者の血管
    • 製剤
    • 必要速度
    • カテーテルの性能
    • 機器の性能
  • 輸液セットを輸血セットの代用にしない
    • 輸血用血液製剤は単独投与が原則。
    • 他薬剤と混注しない。

照合はベッドサイドで閉じる

    • 本人に下記の情報などを名乗ってもらう。
    • 本人に確認する情報の例
      • 氏名
      • 生年月日
    • リストバンドと照合する。
  • 一患者ずつ確認する対象
    • 患者
    • 指示
    • 適合票
    • 製剤本体
    • 電子照合
  • 照合項目の例
    • 患者氏名
    • 血液型
    • 製剤名
    • 製造番号
    • 有効期限
    • 適合試験結果
    • 照射表示
  • 複数名確認と電子照合は、院内手順どおり実施する
  • 確認後に患者・製剤から離れた場合は、接続前に再照合する

輸血の手順

  1. 指示・同意・体制を確認
    • 開始前に確認する項目
      • 目的
      • 製剤
      • 単位数
      • 速度
      • 検査
      • 同意
      • 過去の副反応
      • 連絡方法
    • 緊急時は救命を優先する運用がある。
  2. 製剤を受け取り、外観と表示を確認
    確認する状態
    • 保管状態
    • 搬送状態
    • 破損
    • 漏れ
    • 変色
    • 凝固
    • 著しい凝集
    • 期限

    異常があれば使用しない。

  3. ベッドサイドで患者と製剤を照合
    一患者ずつ確認する対象
    • 患者
    • 指示
    • 適合票
    • 製剤本体
    • 複数名で照合する。
    • 電子照合も併用することが望ましい。
    • 院内手順に従う。
  4. 輸血セットを接続
    • 接続部を清潔に扱い、指定された方法でプライミング。
    • 患者側ルートの開通と刺入部を確認する。
  5. 最初の5分間はベッドサイドを離れない
    • ゆっくり開始する。
      観察する項目
      • 患者の訴え
      • 意識
      • 皮膚
      • 呼吸
      • 脈拍
      • 血圧
    • 急性反応を疑えば直ちに止める。
  6. 15分頃に再評価し、その後も継続
    再評価する項目
    • バイタル
    • 症状
    • 刺入部
    • 滴下
    • 残量

    速度変更は患者状態と指示を再確認して行う。

  7. 終了後も観察し、記録
    • 終了時の確認
      • 患者
      • 製剤
      • 製造番号
      • 終了時刻
      • 投与量
      • バイタル
      • 症状
    • 遅れて出る副反応も説明する。
速度の読み方
  • 日本赤十字社が示す一般成人の速度例
    • 開始10～15分は約1 mL/分。
    • その後は約5 mL/分。
  • 成人の速度例を一律に当てはめない状況の例
    • 心不全
    • 腎機能低下
    • 高齢
    • 小児
    • 急速輸血
  • 滴下数への換算に関わる条件
    • 輸血セットの滴数
    • ポンプ
    • 製剤
    • 指示
  • 時間だけを優先せず、患者の耐容性と製剤の使用条件を確認する

観察の時間軸

  • 輸血前：副反応と区別するための基準値と症状を記録
  • 開始～5分：

    ベッドサイドを離れず観察する。

    警戒する急性反応の例
    • 急性溶血
    • アナフィラキシー
    • 細菌感染
  • 15分頃
    • 患者のそばでバイタルと全身状態を再評価する。
    • 再確認する項目
      • 速度
      • 刺入部
      • 製剤
  • その後
    • 院内で定めた間隔で継続観察する。
    • 患者に知らせてほしい症状を伝える。
  • 終了後：

    終了時だけでなく経過を見る。

    意識する副反応の例
    • TRALI
    • TACO
    • 感染
    • 遅発性反応
「15分」の意味を分ける
  • 一般的な目安では、開始後5分間はベッドサイドで観察する。
  • 15分頃に再度観察する。
  • 最初の10～15分間は、成人では遅い速度で投与する。
  • 施設が開始後15分間の継続観察を定めている場合は、院内手順に従う。

症状から考える副反応

一つの症状を一つの原因に決めない

  • 症状の例
    • 発熱
    • 悪寒
    原因候補の例
    • 発熱性非溶血性反応
    • 溶血
    • 細菌感染
  • アレルギー反応を考える症状の例
    • 蕁麻疹
    • 掻痒
    • 呼吸と循環の変化を同時に確認する。
  • 呼吸の変化の例
    • 呼吸困難
    • SpO₂低下
    原因候補の例
    • TRALI
    • TACO
    • アナフィラキシー
  • 急性溶血などを含む重篤反応を考える症状の例
    • 血圧低下
    • 疼痛
    • 赤褐色尿
  • 細菌汚染を含めて緊急対応する症状の例
    • 高熱
    • 戦慄
    • ショック

TACOとTRALIを呼吸困難だけで決めない

  • TACO：

    循環過負荷。

    評価の手がかりの例
    • 高血圧
    • 頸静脈怒張
    • 浮腫
    • 体液過剰
  • TRALI（輸血関連急性肺障害）
    • 低酸素と肺水腫像を生じる。
    • 伴うことがある所見
      • 発熱
      • 低血圧
  • 合わせて評価する情報
    • 心不全歴
    • 輸液量
    • 体重
    • 尿量
    • 聴診
    • 画像
    • 検査
  • ベッドサイドで断定せず、輸血を止めて緊急評価する

副反応を疑ったときの初動

止める → 見る → 呼ぶ → 確かめる

  1. 輸血を直ちに中止し、自己判断で再開しない
  2. 患者の評価
    • 意識
    • 気道
    • 呼吸
    • 循環
    • バイタル
    • 症状
    • 応援を呼ぶ。
    • 連絡する部門・担当者
      • 医師
      • 輸血部門
  4. 再照合する対象
    • 患者
    • 指示
    • 製剤
    • 製造番号
    • 適合票
  5. 静脈路は院内手順に従い、新しいセットで生理食塩液などへ切り替える
    • バッグと輸血セットを捨てない。
    • 指示を確認する事項の例
      • 検体採取
      • 返却
      • 培養
  7. 記録する項目
    • 症状
    • 時刻
    • 投与量
    • 対応
    • 報告先
    • 患者経過
同じルートをそのまま流さない
  • 副反応を疑った製剤が残る輸血セットから生理食塩液を流し込まない。
  • ライン確保の方法は患者状態と院内手順で決める。

終了後・遅れて出る変化

バッグが空になっても観察は終わらない

  • 終了後も確認する変化
    • 発熱
    • 悪寒
    • 発疹
    • 息切れ
    • 浮腫
    • 体重増加
  • 遅れて現れる変化の確認
    • 黄疸
    • 褐色尿
    • 尿量低下
    • 貧血症状の再出現
  • 終了後に確認する治療経過
    • 出血の持続
    • 期待した検査値の改善が得られない
    • 期待した症状の改善が得られない
  • 退院後に症状が出たときの連絡先と、輸血を受けたことの伝え方
  • 発症時期が異なる有害事象の例
    • 遅発性溶血
    • 同種抗体
    • 感染症
    • 輸血後GVHD
  • 症状と輸血歴を結びつけて共有する。

報告・記録

患者の経過と製剤を追跡できる形にする

  • 目的と製剤の記録
    • 目的
    • 製剤名
    • 血液型
    • 製造番号
    • 単位数
    • 投与量
  • 実施条件の記録
    • 開始時刻
    • 終了時刻
    • 速度変更
    • 使用ルート
    • 使用機器
  • 各時点のバイタルと症状を記録
    • 輸血前
    • 5分
    • 15分頃
    • 継続中
    • 終了後
  • 副反応と対応の記録
    • 副反応の有無
    • 発症時刻
    • 残量
    • 対応
    • 医師への報告
    • 輸血部門への報告
  • 説明と評価の記録
    • 患者説明
    • 効果判定
    • 退院後の連絡事項
  • 特定生物由来製品の記録項目の例
    • 患者氏名
    • 患者住所
    • 製品名
    • 製造番号
    • 投与日
    • 少なくとも使用日から20年を下回らない期間の保管が必要。
  • 施設の輸血管理記録へ確実に残す。
