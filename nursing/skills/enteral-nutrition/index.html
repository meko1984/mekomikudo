経管栄養

  • 正しい消化管の注入口から、指示されたものを安全に届ける。

指示に従って投与するもの

  • 栄養剤
  • 水
  • 薬剤
  • 投与量だけでなく、下記の変化までみる。

変化を見る項目

  • 呼吸
  • 腹部
  • 排便
  • 代謝
学習用
個別に確認する事項
  • 栄養剤
  • 投与経路
  • 投与方法・速度
  • フラッシュ水
  • 薬剤
  • チューブ管理
  • これらは患者ごとの指示、製品の電子添文、院内手順を優先する。
注入を行わない状態
  • チューブ先端位置が確認できない
  • 鼻元の長さが変わった
  • 嘔吐
  • 激しい咳
  • 呼吸悪化
  • 上記の状態がある場合は、栄養剤・水・薬剤を入れない。

経管栄養とは

  • 経鼻・経口チューブの留置先
    • 胃
    • 十二指腸
    • 空腸

    鼻または口から留置する。

  • 胃瘻：腹壁から胃へ造設した瘻孔を使う
  • 胃空腸瘻・腸瘻：胃を越えて小腸へ投与する
  • 胃内投与：胃の貯留能を利用でき、間欠・ボーラス・持続などが選ばれる
  • 幽門後投与：小腸へ直接入るため、一般にポンプによる持続投与など慎重な速度管理が必要になる

投与指示で確認する6項目

開始前に声に出して照合
  • 患者：氏名・生年月日など2つ以上の識別情報
  • 栄養剤
    • 製品
    • 濃度
    • アレルギー
    • 使用期限
    • 保存・開封条件
  • 投与先
    • 胃か小腸か
    • チューブ種類
    • 正しい栄養注入口
  • 方法
    • ボーラス
    • 間欠
    • 持続
    • 重力滴下
    • ポンプ
  • 量・速度
    • 1回量
    • 時間量
    • 開始・増量方法
    • 休止条件
  • 水分
    • フラッシュに使う水
    • 1回量
    • 頻度
    • 24時間総量

栄養剤の種類

  • 半消化態・標準的な製剤：蛋白質を主な窒素源とし、消化機能が保たれている場合に広く使われる
  • 消化態：ペプチドなど、より分解された窒素源を含む
  • 成分栄養：アミノ酸を窒素源とし、脂質が少ない製剤などがある
  • 病態別・高濃度・高蛋白などの選択で考えること
    • 疾患
    • 体液管理
    • 必要量
  • 濃度が高いほど優れているわけではない。
  • 栄養量と合わせて確認すること
    • 自由水
    • 電解質
    • 食物繊維
    • 脂質
    • 薬剤との相互作用

    院内で承認された確認方法を使う。

  • 位置が疑わしければ使用を止めて再確認する。

必要物品と準備

  • 指示された経腸栄養剤
  • 経腸栄養専用の投与セット・バッグ
  • 経腸栄養用シリンジ
  • 指示されたフラッシュ用の水
  • 必要時、経腸栄養ポンプ
  • 延長チューブ・接続アダプタ
  • 手袋
  • 清拭物品
  • 廃棄物袋
  • ラベル
  • 記録用紙または端末
  • 必要時、血糖測定・SpO₂測定物品
清潔な作業面で準備する
  • 手指衛生を行い、容器・接続部へ触れる回数を減らす。
  • 表示する情報
    • 開封・調製時刻
    • 患者
    • 製品
    • 量
  • 製品表示と院内基準に従う管理
    • 保存
    • 開封後の使用時間
    • 投与セット交換
  • 残った栄養剤へ新しい栄養剤を継ぎ足さない。
  • 冷蔵品は製品表示に従って扱い、電子レンジなどで不均一に加温しない。

投与の手順

  1. 患者・指示・栄養剤を照合する
    投与指示の確認
    • 投与先
    • 方法
    • 量
    • 速度
    • フラッシュ
    • 血糖測定
    • 休止条件
  2. 説明し、上半身を起こす
    • 禁忌がなければ30～45度を目安に上半身を挙上する。
    • ずり落ちや圧迫を防ぎ、呼吸と腹部を観察できる体位にする。
  3. チューブ位置と注入口を確認する
    • チューブ使用前の確認
      • 外部長
      • 固定
      • 屈曲
      • 患者症状
    • 胃瘻・胃空腸瘻では各ポートの役割を確認し、栄養注入口を選ぶ。
  4. 指示された水でフラッシュする
    • フラッシュ時にないか確認すること
      • 抵抗
      • 疼痛
      • 漏れ
    • 水の種類と量を決める確認
      • 年齢
      • 水分制限
      • チューブ径・先端位置
      • 製品
  5. 専用コネクタで接続して開始する
    • 投与セットを患者側からたどり、下記へつながっていないことを確認する。
      経管栄養セットの誤接続を確認
      • 静脈
      • 気道
      • ドレーン
    • 指示速度で開始する。
  6. 投与中の反応を観察する
    投与中の確認
    • 呼吸
    • 意識
    • 悪心・嘔吐
    • 逆流
    • 腹痛・膨満
    • 下痢
    • 機器アラーム
    • 接続・漏れ
  7. 終了後にフラッシュして記録する
    • 指示量の水でチューブ内を清潔に保ち、キャップを閉じる。
    • 実投与量と水分量、反応を記録する。
  • 前回投与からの間隔を一律に「最低2時間」とはしない。
  • 投与間隔を考える条件
    • 投与方法
    • 胃排出
    • 先端位置
    • 患者の耐容性
    • 処方時刻

投与方法の違い

胃の貯留能と患者の耐容性で選ぶ

  • ボーラス：シリンジなどで一定量を比較的短時間に投与
  • 間欠：重力滴下やポンプで一定時間かけ、休止時間を設ける
  • 持続：ポンプなどで長時間、一定速度で投与
  • 幽門後・空腸投与は、急速なボーラスを避けて持続投与が選ばれることが多い
  • 開始・増量・減量・休止は自己判断で変えず、指示を確認する
  • 滴下数の計算では、投与セットの滴下係数を必ず製品表示で確認する。
  • ポンプ使用時も人の目で照合すること
    • 予定量と実投与量
    • バッグ残量

誤嚥を防ぐ観察と体位

  • 投与中は、禁忌がなければ上半身30～45度挙上を目安にする。
  • 投与後も患者の状態と投与方法に応じて挙上を続け、直後の仰臥位を避ける。
  • 誤嚥リスクを高める状態
    • 鎮静
    • 意識低下
    • 咳嗽低下
    • 嘔吐
    • 逆流
    • 腹部膨満
  • 誤嚥を疑う変化の観察
    • 咳
    • 湿性嗄声
    • ゴロゴロした呼吸音
    • SpO₂低下
    • 頻呼吸
    • 発熱
  • 耐容性を評価する観察
    • 腹部
    • 排便
    • 嘔吐
    • 呼吸
    • 全身状態

    胃内容残量だけで耐容性を判断しない。

  • 口腔ケアで減らすこと
    • 乾燥
    • 痰
    • 舌苔
    • 歯垢

    食べていなくても口腔ケアを続ける。

薬剤をチューブから投与するとき

投与前に薬剤師へ確認
  • チューブ投与が可能な薬剤・剤形か
  • 粉砕してはいけない製剤の確認の例
    • 徐放錠
    • 腸溶錠
    • 舌下錠
    薬剤ごとに薬剤師へ確認する内容
    • 剤形
    • 粉砕可否
  • 胃内・空腸内で吸収や作用が変わらないか
  • 栄養剤との相互作用により、投与前後の休止が必要か
  • 簡易懸濁法について薬剤師へ確認すること
    • 可否
    • 温度
    • 時間
    • 使用する水
    • チューブ径
  1. 栄養投与を止め、位置を確認
    薬剤投与前の確認
    • 正しい患者
    • 薬剤
    • 投与時刻
    • 経路
    • チューブ先端位置
    • 注入口
  2. 前フラッシュ
    • 指示量の水でチューブ内の栄養剤を流す。
    • 通過性を確認する。
  3. 一剤ずつ投与
    • 複数薬剤をまとめない。
    • 薬剤を栄養剤へ混ぜない。
    • 一剤ごとに投与する。
  4. 薬剤間・投与後にフラッシュ
    • 薬剤同士の混合と閉塞を防ぐ。
    • 栄養再開時刻は薬剤ごとの指示に従う。

症状を原因につなげてみる

  • 呼吸器
    • 逆流
    • 誤嚥
    • 誤嚥性肺炎
  • 消化管
    • 悪心・嘔吐
    • 膨満
    • 腹痛
    • 下痢
    • 便秘
  • 代謝
    • 高・低血糖
    • 脱水
    • 過剰水分
    • 電解質異常
  • チューブ
    • 閉塞
    • 移動
    • 抜去
    • 破損
    • 瘻孔周囲漏れ
  • 接続・機器
    • 誤接続
    • 設定間違い
    • 投与不足・過量
下痢を栄養剤だけのせいにしない
  • 下痢の原因として確認すること
    • 抗菌薬
    • 下剤
    • ソルビトール含有薬
    • 感染
    • 便塞栓
    • 投与速度
    • 栄養剤の汚染
  • 下痢の記録
    • 回数
    • 量
    • 性状
    • 開始時期
    • 腹痛・発熱
    • 薬剤変更との関係
  • 栄養剤を自己判断で薄めたり、急に中止・変更したりしない。

再栄養症候群

開始前にリスクを確認
  • 著しい低体重や最近の大きな体重減少
  • 長期間ほとんど食べていない
  • 開始前の低値を確認する電解質
    • リン
    • カリウム
    • マグネシウム
  • 再栄養症候群のリスク確認の例
    • アルコール多飲
    • 吸収障害
    • がん治療
    • 利尿薬
  • 開始量・増量速度、ビタミン・電解質補充は医師・管理栄養士・薬剤師と計画する。
  • 経時的に確認すること
    • リン
    • K
    • Mg
    • 血糖
    • 体重
    • 水分出納
    • 浮腫
  • 直ちに報告する変化
    • 浮腫
    • 呼吸困難
    • 頻脈・不整脈
    • 筋力低下
    • 意識変化
    • けいれん

チューブ・機器の異常

閉塞時に強く押し込まない
  • 閉塞時の確認
    • クランプ
    • 屈曲
    • 接続
    • チューブ外部長
    • ポンプ設定
  • 抵抗や疼痛、瘻孔周囲漏れがあれば注入を止める。
  • 小容量シリンジで強く加圧しない。
  • スタイレットやガイドワイヤを閉塞解除に使わず、再挿入しない。
  • 閉塞解除は製品の電子添文と院内手順に従う。
抜けた・位置が変わった
  • 位置が変わった・抜けたときに止める投与
    • 栄養剤
    • 水
    • 薬剤
  • 自分で押し戻さない。
  • 瘻孔から抜けた場合は造設時期と抜去時刻を確認し、速やかに報告する。
  • 位置変化・抜去時の観察
    • 呼吸
    • 腹痛
    • 出血
    • 漏れ

    再確認・再留置に備える。

すぐに投与を止めて報告する変化

  • 呼吸・意識の変化
    • 激しい咳
    • 呼吸困難
    • SpO₂低下
    • チアノーゼ
    • 意識変化
  • 嘔吐・逆流・誤嚥
    • 繰り返す嘔吐
    • 栄養剤の逆流
    • 誤嚥が疑われる
  • 腹部の変化
    • 強い腹痛
    • 腹部硬直
    • 著明な膨満
    • 消化管出血
  • チューブの異常
    • 外部長変化
    • 抜去
    • 破損
    • 接続外れ
  • 瘻孔周囲の異常
    • 大量漏れ
    • 出血
    • 急な激痛
  • 再栄養症候群を疑う変化の例
    • 不整脈
    • 呼吸悪化
    • 浮腫
    • 筋力低下
  • 機器・投与の異常
    • ポンプ設定間違い
    • 過量投与
    • 静脈・気道・ドレーンへの誤接続が疑われる
