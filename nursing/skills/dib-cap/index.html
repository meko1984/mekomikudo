DIBキャップ

  • 「バッグを外せる栓」だけではない。
  • 膀胱へ尿をためる時間と、安全に排出するタイミングを管理する尿道留置カテーテル用キャップ。
学習用
個別に確認する事項
  • DIBキャップの使用開始・中止
  • 排尿間隔
  • 夜間の排液方法
  • 交換時期
優先する評価・説明書・手順
  • 医師・看護師による個別評価
  • 採用製品の説明書
  • 院内の手順
  • 在宅療養の手順
  • 個別に確認する事項は、上記の評価・説明書・療養環境に応じた手順を優先する。

DIBキャップとは

  • シリコーン製の尿道留置バルーンカテーテルの排尿ファネルへ接続する製品
  • 磁力を利用したふたを片手で開閉し、トイレや容器へ排尿できる
  • 専用アタッチメントを介して採尿バッグへ接続できる
  • 外出・移動・入浴時の採尿バッグによる制約を軽くできる可能性がある
DIBは商品名
  • カテーテルバルブという製品群の一つ。
  • 製品ごとに異なること
    • 形
    • 磁石の有無
    • 接続方法
    • 交換期間

    他社製品へ手順をそのまま流用しない。

使えるかを先に評価する

医療者の評価なしに切り替えない
  • 蓄尿に関わる問題
    • 膀胱容量・コンプライアンスが低い
    • 膀胱内圧が高い
    • 膀胱尿管逆流がある
  • 腎機能・排液に関わる問題
    • 腎機能障害
    • 上部尿路障害
    • 頻回な閉塞
    • 結晶付着
    • 血塊
  • 尿意や膀胱充満感が乏しく、時計に沿った排尿も難しい
  • 安全な開閉に影響する機能
    • 認知機能
    • 手指機能
    • 視力
    • 姿勢保持
    • 上記の機能の問題で安全に開閉できない場合は、医療者が評価する。
    その場合に評価すること
    • 支援方法
    • 使用の適否
  • 排尿介助を決めた時刻に行える支援体制がない
  • 適している場合でも、尿意だけに任せず個別の排尿計画を作る。
  • 尿のたまる速さが変わる要因
    • 水分摂取
    • 利尿薬
    • 発熱
    • 輸液
    • 夜間多尿

使用前の確認

  • 患者
    • 尿意
    • 下腹部膨満・疼痛
    • 発熱
    • 悪寒
    • 側腹部痛
    • 血尿
    • 尿漏れ
  • 計画
    • 最終排尿時刻・量
    • 次回排尿時刻
    • 夜間バッグの使用
    • 介助者
  • カテーテル
    • 固定
    • 牽引
    • 屈曲
    • 亀裂
    • 接続部
    • 尿道口周囲の皮膚
  • キャップ
    • 製品名・型
    • 確実な接続
    • ふたの開閉
    • 異物
    • 白い結晶
    • 汚染
    • 破損
  • 磁石の安全確認
    • MRI予定
    • 植込み型医療機器
    • 磁気の影響を受ける機器・カード類
  • 磁石を使用するDIBキャップはMRI室へ持ち込まない。
  • 植込み型医療機器との距離や対応は、両方の製品説明書と医療者の指示を確認する。

排尿の手順

  1. 時刻と症状を確認する
    • 排尿前の確認
      • 最終排尿時刻
      • 尿意
      • 下腹部膨満・疼痛
      • 発熱
      • 気分不良
    • 予定より遅れている場合は理由も把握する。
  2. 環境と容器を整える
    • トイレまたは患者専用の清潔な計量容器を準備する。
    • 衣服や床への飛散を防ぎ、カテーテルを引っ張らない姿勢にする。
  3. 手指衛生を行う
    • 医療者は標準予防策に従って手袋を使用する。
    • 排出口を接触させない対象
      • 指
      • 便器
      • 容器
  4. 排出口を下へ向けて開く
    • 製品の開閉部を正しく操作し、尿を自然に流す。
    • 下腹部を強く押したり、カテーテルをしごいたりしない。
  5. 流れと尿を観察する
    • 流れと尿の確認
      • 流出の開始
      • 勢い
      • 途絶
      • 量
      • 色
      • 混濁
      • 血液
      • 沈渣
      • におい
    • 流れないときに器具を差し込まない。
  6. 閉鎖・清拭する
    • 流出終了後にふたを確実に閉じる。
    • 外側の水分や汚れを製品指示に沿って清浄綿などで拭き、磁石部に異物を残さない。
  7. 再評価して記録する
    排尿後の確認
    • 下腹部症状
    • 尿漏れ
    • 接続
    • 次回時刻
    記録
    • 排尿時刻
    • 量
    • 性状
    • 症状
    • 介助内容

夜間バッグ・採尿バッグへつなぐとき

  • DIBキャップ専用アタッチメントを使い、キャップと採尿バッグへ十分に差し込む
    • 接続前後に手指衛生を行い、接続部へ触れない。
    • 不用意な着脱を減らす。
    • バッグは膀胱より低く保つ。
    • バッグを床へ置かない。
    チューブで防ぐ状態
    • 屈曲
    • 圧迫
    • たるみ
  • キャップが開放され、膀胱からバッグまで尿が流れる状態を確認する
  • 朝にバッグを外してキャップ管理へ戻す方法は、使用製品と療養計画どおりに行う
バッグをつないだだけでは流れない
膀胱からバッグまで一続きに確認
  • キャップの開閉状態
  • アタッチメントの差し込み
  • チューブの屈曲
  • バッグの高さ

異常時の対応

  • 尿が出ないときの確認
    • キャップの開放
    • 屈曲・圧迫
    • 接続
    • 膀胱部症状

    強い膨満や痛みがあれば直ちに報告する。

  • 尿漏れの確認
    • ふたの閉鎖
    • 異物・結晶
    • 接続の浅さ
    • 破損
    尿道周囲からの漏れで考える原因の例
    • 閉塞
    • 膀胱けいれん
  • 血尿・血塊の確認
    • 量と色
    • カテーテル牽引
    • 疼痛
    • 流出

    閉塞する前に報告する。

  • 感染を疑って報告する変化
    • 発熱
    • 悪寒
    • 側腹部痛
    • 意識変化
    • 上記の変化がある場合は、尿路感染や全身感染を疑って報告する。
    報告に添える所見
    • バイタルサイン
    • 尿所見
  • そのまま戻さないキャップの状態
    • 外れた
    • 床へ落ちた
    • 破損した
    • 上記の状態の場合は、そのまま戻さない。
    • 清潔に保護する。
    • 製品・施設手順で交換を依頼する。
  • 予定時刻に排尿できない：尿量増加による過伸展を防ぐため、代替の排尿方法と支援者を早めに確保する
自己判断で行わない
  • キャップ内部へ綿棒や器具を差し込む
  • 自己判断で行わないカテーテル操作
    • しごく
    • 洗浄する
    • 交換する
  • 尿が出ないまま長時間待つ
  • 磁石部の破損や閉鎖不良がある製品を使い続ける

類似する製品・方法

DIBキャップライト

  • 磁石を使わない同社の開閉式キャップ。
  • 同名部品が自己導尿用カテーテルや採尿バッグの排出口にも使われている。
使用前の確認
  • 接続対象
  • 型番
  • 交換方法

DIBキャップの代用品と決めつけない。

Flip-Flo™ Catheter Valve / Ugo Catheter Valve

  • レバーで開閉する海外のカテーテルバルブ。
  • 膀胱へ尿をためて任意に排出する目的は似ている。
DIBキャップと異なること
  • 構造
  • 接続
  • 使用期間
  • 禁忌
日本で使用する前に確認
  • 流通
  • 承認
  • 施設採用

レッグバッグ・採尿バッグ

  • 尿を持続的に排出して袋へためる方法。
  • 活動性を保つ目的は共通するが、膀胱へ尿をためるDIBキャップとは排尿管理が違う。
  • 夜間のみバッグへ接続する計画もある。

単純なカテーテル栓・プラグ

  • 排尿のたびに抜き差しする製品がある。
  • 適合性が不明な栓を流用しない。
注意すること
  • 自然脱落
  • 尿の飛散
  • 接触汚染
  • 紛失
  • カテーテルバルブが採尿バッグより尿路感染を減らすかは、現在も十分な根拠がない。
  • 分けて評価すること
    • 患者の希望や生活上の利点
    • 膀胱・腎機能
    • 安全に操作できる条件

交換・日常管理

  • メーカーはDIBキャップを1か月以内、またはカテーテル交換時に新しいものへ交換するよう案内している
  • 使用期間内でも交換を相談する異常
    • 閉鎖不良
    • 漏れ
    • 破損
    • 著しい汚染・結晶付着
    • 接続不良
  • キャップやアタッチメントの再使用・洗浄方法は、製品説明書にない方法を追加しない
  • 留置カテーテル自体の必要性は定期的に見直し、不要なら早期抜去を検討する

    • 接続状態
