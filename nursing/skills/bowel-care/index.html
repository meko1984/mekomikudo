便処置
浣腸・坐薬・摘便

  • 「便が出ない」だけで処置を決めない。
安全な排便援助を選ぶために確認する項目
  • 便の位置
  • 便の硬さ
  • 腹部症状
  • 薬剤
  • 患者の危険因子
学習用
  • 成人の一般的な直腸内処置を扱う。
個別に確認する事項
  • 実施の可否
  • 薬剤
  • 容量
  • 挿入方法
  • 保持時間
  • 実施者の範囲
優先する条件・指示・手順
  • 患者の状態
  • 医師の指示
  • 薬剤の電子添文
  • 器具の電子添文
  • 院内手順
  • 個別に確認する事項は、上記の条件・指示・手順を優先する。

処置の前に止まる条件

腹痛を便秘と決めつけない
処置前に評価が必要な症状
  • 突然または強い腹痛
  • 腹膜刺激症状
  • 著明な腹部膨満
  • 嘔吐
  • 発熱
  • 血便
  • 黒色便
  • 排ガス停止
除外が必要な病態の例
  • 腸閉塞
  • 炎症
  • 出血
  • 穿孔
  • 上記の症状がある場合は、これらの病態を除外するまで直腸処置を進めない。
実施前に医師・指導者へ確認
  • 病態の確認
    • 腸管出血
    • 腹腔内炎症
    • 腸閉塞
    • 穿孔
    • いずれかの病態またはその疑いがある場合は確認する。
  • 治療歴・局所病変の確認
    • 直腸の手術直後
    • 肛門の手術直後
    • 大腸の手術直後
    • 放射線治療後
    • 重い痔核
    • 重い裂肛
    • 重い直腸病変
  • 感染・出血リスクの確認
    • 好中球減少
    • 血小板減少
    • 出血傾向
    • 抗凝固薬使用
  • 循環リスクの確認
    • 重い心疾患
    • 不整脈
    • 循環不安定
  • 脊髄損傷、特にT6以上など自律神経過反射の危険
  • 個別判断が必要な状態の例
    • 妊娠
    • 炎症性腸疾患
    • ストーマ

まず排便を評価する

便だけでなく経過と全身を見る

経過と全身の確認
  • 最終排便
  • 普段の排便回数
  • 普段の便の形
  • 排ガス
  • 残便感
  • 腹痛
  • 膨満
  • 悪心
  • 嘔吐
  • 食事
  • 水分
  • 活動
  • 薬剤
  • 直腸診は必要性と禁忌を判断する。
  • 実施する場合は、権限・院内手順に沿って行う。
  • 便の評価
    • 量
    • 硬さ
    • 色
    • 血液
    • 粘液
    • ブリストル便形状スケール
  • 排出の評価
    • 便意
    • いきみ
    • 排出困難
    • 肛門痛
    • 残便感
  • 腹部・消化器症状の評価
    • 腹部膨満
    • 圧痛
    • 腸蠕動音
    • 悪心
    • 嘔吐
    • 食欲
  • 生活・排泄環境の評価
    • 水分摂取
    • 食事摂取
    • 活動
    • 排泄環境
    • トイレ動作
  • 便秘に関わる薬剤の例
    • オピオイド
    • 抗コリン薬
    • 鉄剤
  • 使用歴と効果を確認するもの
    • 下剤
    • 浣腸
    • 坐薬

処置を使い分ける

便の位置・硬さ・薬剤作用で選ぶ

  • 坐薬：直腸で溶け、薬剤に応じて蠕動や排便反射を促す。
浣腸で利用する作用
  • 刺激
  • 軟化
  • 滑り
  • 液を直腸へ入れる。
  • 摘便：直腸内に触れる硬便を、必要時に少量ずつ除去する。
  • 慢性便秘の管理は直腸処置だけで完結しない。
  • 長期計画で評価する項目の例
    • 原因
    • 生活
    • 経口薬
    • 排便姿勢
    • 骨盤底機能

    評価結果から長期計画を見直す。

共通の準備

  • 指示された浣腸薬または坐薬
  • 水溶性潤滑剤
  • 感染防護用品
    • 非滅菌手袋
    • エプロン
    • 必要時マスク
    • 必要時眼の防護
  • 防水・排泄用品
    • 防水シート
    排泄方法に合わせて選ぶ用品
    • 便器
    • ポータブルトイレ
    • おむつ
  • 清潔・交換用品
    • 清拭物品
    • 陰部洗浄物品
    • 交換用下着
    • 交換用パッド
  • 廃棄物袋
  • 必要時の観察用品
    • 血圧計
    • パルスオキシメータ
  1. 本人確認と説明
    説明する内容
    • 目的
    • 方法
    • 予想される便意
    • 予想される腹痛
    • 途中で中止できること

    説明し同意を得る。

  2. 排泄方法を先に決める
    排泄方法の確認
    • トイレ移動の可否
    • 便器の使用
    • おむつの使用
    • ナースコール
    • 転倒リスク
  3. プライバシーと保温
    • 閉めるもの
      • カーテン
      • 扉
    • 露出を最小限にする。
    • 配慮する項目
      • 換気
      • 臭気
  4. 左側臥位を基本に調整
    • 膝を軽く曲げ、安定させる。
    • 無理に固定しない条件
      • 疼痛
      • 麻痺
      • 術後制限

浣腸

直腸壁に沿わせ、抵抗に逆らわない

  • 先端を十分に潤滑する。
  • 製品の挿入目安・ストッパーに従ってゆっくり挿入する。
注入せず中止するサイン
  • 強い抵抗
  • 鋭い痛み
  • 出血

いずれかがあれば注入せず中止する。

  1. 薬剤を照合
    • 薬剤照合・状態確認
      • 患者
      • 製品
      • 濃度
      • 容量
      • 期限
      • 禁忌
      • 容器破損
    • 温め方が必要な製品は表示に従い、過熱しない。
  2. 左側臥位と防水
    • 臀部を観察して防水シートを敷く。
    • 肛門が見える範囲だけ露出する。
  3. 先端を潤滑して挿入
    • 臀部を開き、肛門・直腸の走行に沿わせる。
    • 成人でも固定した深さを一律に使わず、製品表示と抵抗で判断。
  4. ゆっくり注入

    患者へ呼吸を促す。

    観察する項目
    • 表情
    • 腹痛
    • 冷汗
    • 気分不良

    抵抗時に圧をかけない。

  5. 抜去して排便を援助
    • 可能な範囲で薬剤の指示時間を保つ。
    • 便意が強ければ我慢を強制しない。
    • 事前に決めた排泄方法に合わせ、安全に便器またはトイレでの排泄を援助する。
穿孔と腸管外注入を防ぐ
  • 先端を無理に進めない。
  • 直ちに報告・評価する変化
    • 注入時の強い痛み
    • 抵抗
    • 出血
    • 処置後も続く腹痛
    • 処置後も続く腹部膨満

    いずれかがあれば直ちに報告して評価する。

坐薬

肛門括約筋を越えて直腸内へ

照合する項目
  • 薬剤名
  • 規格
  • 個数
  • 必要時に水溶性潤滑剤を使用する。
製品表示に従う事項
  • 挿入方向
  • 挿入深さ
  • 保持時間
  • 保管方法
  1. 薬剤を照合
    坐薬の照合・状態確認
    • 患者
    • 薬剤
    • 規格
    • 個数
    • 期限
    • 包装
    • 保管状態
  2. 左側臥位へ

    防水シートを敷く。

    肛門周囲の観察
    • 傷
    • 出血
    • 便塊
  3. ゆっくり挿入
    • 臀部を開く。
    • 呼気に合わせて肛門括約筋を越える位置まで挿入する。
    • 無理に押し込まない。
  4. 安楽な体位で待つ
    • すぐ排出されないよう必要時間を保つ。
    • 強い便意や苦痛を我慢させない。
  5. 効果を観察
    坐薬の効果と反応の確認
    • 排便までの時間
    • 便量
    • 便の性状
    • 腹痛
    • 出血
    • 薬剤の排出

摘便

触れる硬便を少量ずつ

  • 十分に潤滑した手袋の示指一本を、直腸壁に沿ってゆっくり挿入。
  • 硬便を小さく分け、粘膜や肛門括約筋を傷つけないよう少量ずつ除く。
  1. 適応と危険因子を再確認
    摘便前の確認
    • 直腸内の硬便
    • 他の方法の効果
    • 出血リスク
    • 感染リスク
    • 循環リスク
    • 自律神経過反射リスク
  2. 左側臥位と観察準備
    • 膝を軽く曲げる。
    • 防水シートを敷く。
    • 必要時に処置前後で測定する項目
      • 脈拍
      • 血圧
  3. 十分に潤滑
    • 示指へ水溶性潤滑剤を十分につける。
    • 深呼吸と呼気を促す。
  4. ゆっくり挿入

    直腸壁に沿って示指一本を進める。

    中止するサイン
    • 痛み
    • 抵抗
    • 出血

    いずれかがあれば中止。

  5. 便塊を小さく除去
    • 無理に一塊で引き出さない。
    • 短時間ずつ行う。
    • 確認する患者の状態
      • 反応
      • 疲労
  6. 終了後の清潔と再評価

    肛門周囲をやさしく清潔にする。

    終了後の再評価
    • 腹部症状
    • 排便感
    • 出血
    • バイタルサイン

処置中の中止サイン

痛み・出血・循環変化で止める

処置を中止する変化
  • 強い腹痛
  • 強い肛門痛
  • 出血
  • 強い抵抗
  • 顔面蒼白
  • 冷汗
  • 悪心
  • めまい
  • 意識変化
  • 脈拍低下
  • 血圧変化
  • 処置を中止して安全な体位をとる。
  • 応援を要請する。
  • 観察し、報告する。
迷走神経反射
  • 迷走神経反射の徴候
    • 徐脈
    • 血圧低下
    • 冷汗
    • 悪心
    • 失神

    直腸刺激で起こすことがある。

  • 処置を止めて確認する項目
    • 意識
    • 気道
    • 呼吸
    • 脈拍
    • 血圧
  • 急変対応へ移る条件
    • 症状が続く
    • 重い徐脈
    • 重い低血圧
    • 意識障害
自律神経過反射
  • 自律神経過反射の徴候
    • 急激な血圧上昇
    • 頭痛
    • 発汗
    • 紅潮
    • T6以上の脊髄損傷などでは、直腸刺激で起こすことがある。
  • 処置を中止する。
  • 上体を起こす。
  • 血圧を確認して院内手順に沿う。

処置後の観察とケア

  • 排便
    確認する項目
    • 量
    • 硬さ
    • 色
    • 血液
    • 粘液
    • 薬剤排出
    • 残便感
    • 排ガス
  • 全身・腹部
    確認する項目
    • 腹痛
    • 膨満
    • 悪心
    • めまい
    • 意識
    • 脈拍
    • 血圧
    • 疲労
  • 肛門・皮膚
    確認する項目
    • 出血
    • 疼痛
    • 裂傷
    • 発赤
    • びらん
    • 失禁関連皮膚炎
  • こすらず除去するもの
    • 便
    • 薬液
  • 皮膚を乾燥させる
  • 必要時は皮膚保護剤を製品表示に従って使用
  • 無理のない範囲で支援する項目
    • 水分摂取
    • 食事
    • 活動
    • トイレ環境
    • 定時排便
  • 処置を繰り返さないと出ない場合は、便秘の原因と長期計画を見直す
