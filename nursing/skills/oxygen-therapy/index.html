酸素療法

  • 酸素を「多く入れる」のではなく、患者に合う目標範囲へ届ける。

SpO2が高いほど安全、ではない
  • 過剰な酸素も害になりうる。
  • 数値だけを100%へ近づけず、決められた目標範囲へ調整する。

目的

最初に決める目標SpO2

代表的な成人急性期の範囲

多くの成人：94〜98%

高二酸化炭素血症のリスク：88〜92%

  • 後者は血液ガス結果が得られるまでの代表的な範囲。
  • 目標範囲は次の条件に応じて変わる。
個別の目標範囲を確認
  • 既往
  • 疾患
  • 個別指示

目標値と患者を同時に見る

SpO2だけで投与量を決めない。

合わせて評価
  • 呼吸仕事量
  • 意識
  • 循環
  • 波形
  • 信号
  • 血液ガス
  • 投与前後の変化
一酸化炭素中毒、蘇生直後、特定薬剤による肺障害などは別の指針が必要。

観察項目

状態を確認する場面
  • 安静時
  • 体動時
  • 食事時
  • 排泄時
  • 睡眠時

酸素を外した場面や移動後は再評価する。

酸素投与デバイス

流量と濃度の目安

「1L/分ごとにFiO2が約4%上がる」は簡便な覚え方
  • 鼻カニューレの固定換算式ではない。
  • 流量から濃度を決めつけず、患者の反応と目標SpO2で評価する。
  • 流量・濃度の範囲は代表的な成人用。
  • 製品ごとに違う。
  • 代表値より優先するもの
    • 器具の表示
    • 電子添文
    • 医師の指示

必要物品

  • 医療用酸素供給源
  • 酸素流量計
  • ボンベ使用時の酸素用圧力調整器
  • 指示された酸素投与デバイス
  • 酸素供給チューブ
  • パルスオキシメータ
  • 必要時、皮膚保護用パッド
  • 必要時、固定用テープ
  • 必要時、製品指定の加湿器
  • 加湿器に指定された水
  • 必要時、火気厳禁の表示
  • 患者状態に応じた救急物品
  • 患者状態に応じた吸引物品
  • 加湿は一律ではない。
  • 加湿の判断材料
    • 流量
    • 乾燥
    • 不快感
    • 分泌物
    • 投与時間
    • 製品の接続条件
    • 院内手順

手順

  1. 本人・指示・目標を照合
    開始前に照合
    • 投与理由
    • デバイス
    • 流量またはFiO2
    • 目標SpO2
    • 開始条件
    • 調整条件
  2. 投与前の状態をつかむ
    投与前の観察
    • 呼吸
    • SpO2と信号
    • 意識
    • 循環
    投与前に合わせて確認
    • CO2貯留リスク
    • 直近の血液ガス
  3. 体位・環境・供給源を整える
    • 呼吸しやすい体位を整える。
    • 火気と油脂を遠ざける。
    供給系統の確認
    • ガス名
    • 残量
    • 接続口
    • チューブ
  4. 接続して指示値へ設定
    • 流量計とチューブを確実に接続する。
    • 酸素が先端まで出ていることを確認する。
  5. デバイス固有の準備
    • ベンチュリーは指定アダプターと流量を使う。
    • リザーバーは装着前にバッグを膨らませる。
  6. 装着して圧迫・閉塞を除く
    • 鼻・口へ正しく合わせる。
    • 締めすぎず、側孔・空気取入口を塞がない。
    • 耳や頬を保護する。
  7. 反応を再評価し記録
    • 数分以内に次を再確認する。
      投与後の再評価
      • 呼吸
      • SpO2
      • 意識
      • 循環
    • 目標外・悪化は報告し、指示や手順に沿って調整。
急にSpO2が下がったら
  • まず患者を見る。
  • 気道・呼吸・循環を評価しながら、次を同時に確認する。
    急な低下時の確認
    • プローブ
    • 酸素源
    • 流量
    • 接続
    • チューブ
    • デバイス位置

酸素ボンベの残量確認

最初に読む2つ

  • 容器の内容積「V」
  • 圧力計の値
  • ガス名の医薬品ラベルも確認。
  • 通称「500Lボンベ」でも、計算には刻印・仕様の内容積を使う。

MPa表示の概算

残量（L）≒ 内容積（L）× 圧力（MPa）× 10

理論使用時間（分）≒ 残量（L）÷ 流量（L/分）

概算の例：条件
  • 内容積 3.4L
  • 圧力 10MPa
  • 流量 2L/分
概算の例：結果
  • 残量 約340L
  • 理論使用時間 約170分

計算値を使い切らない

安全余裕に見込む要因
  • 搬送時間
  • 待ち時間
  • 流量変更
  • 機器誤差
  • 交換基準と安全係数は院内手順に従う。
  • 十分な残量を選ぶ。
  • 搬送中も圧力計を確認する。
旧単位の圧力計
  • kgf/cm²表示：残量（L）≒ 内容積（L）× 圧力（kgf/cm²）
  • 1MPa ≒ 10.2kgf/cm²
  • どちらも概算。製品仕様と院内換算表を優先
  • 安全余裕として残量に0.8をかける方法もある。
  • 全国共通の固定値ではないため、計算式へ一律には組み込まず、院内手順を確認する。

関連知識

パルスオキシメータには誤差がある

セットで評価
  • 数値
  • 波形
  • 信号
  • 患者の症状
  • 次の要因などで測定がずれる。
    誤差の要因
    • 体動
    • 低灌流
    • 冷え
    • 爪
    • 皮膚色
    • センサー位置
  • 疑わしい値は測り直し、必要時は血液ガスへ。

CO2貯留をSpO2だけで否定しない

酸素化が保たれていても、換気不全はありうる。

CO2貯留を考える確認
  • 傾眠
  • 頭痛
  • 呼吸の浅さ
  • 既往

高リスクでは目標範囲と血液ガスを重視する。

酸素は燃えないが、燃焼を強くする

医療施設では使用設備の周囲5m以内を火気禁止。

  • 避けるもの
    • 喫煙
    • 火花
    • 可燃物
  • バルブや圧力調整器へ油脂を付けず、ボンベは固定して静かに開閉する。

高濃度・長時間投与にも注意

必要な濃度を、必要な時間だけ。

  • 高濃度酸素の長時間投与では酸素中毒の危険がある。
  • 目標内で減量・中止できるか継続して見直す。

HFNC・NPPVとの違い

通常酸素から呼吸補助へ

  • HFNC：加温加湿した高流量ガスを太い鼻カニューレから送る。
  • NPPV：密着するマスクから陽圧をかける。
  • 酸素化と換気を補助する。
  • どちらも通常酸素とは機器・設定・観察が異なる。
  • 詳しい導入と管理は別ページで扱う。
