胸腔ドレーンの安全原則

自分の判断で変えない・止めない
  • 装置は立てたまま、挿入部より低い位置に保つ。
  • 防ぐべき状態
    • 接続の緩み
    • 屈曲
    • 圧迫
    • ベッド柵への挟み込み
    • 深い垂れ下がり

    これらがないか、患者から装置まで確認する。

  • 吸引圧を自己判断で変更せず、水封水や吸引室は製品の目盛・添付文書で確認する。
  • ルーチンのクランプや強いミルキング・ストリッピングは行わない。
  • 排液だけで判断せず、下記を同時にみる。
    排液と同時に見る項目
    • 呼吸
    • 循環
    • 疼痛
    • 装置全体

目的と主な適応

胸腔内から空気・液体を排出する

  • 気胸：空気を排出し、肺の再膨張を助ける
  • 血胸：血液を排出し、量と性状を観察する
  • 胸水・乳び胸：貯留液を排出し、呼吸を助ける
  • 膿胸：感染した胸水・膿を排出する
  • 胸部手術後に排出するもの
    • 空気
    • 血液
    • リンパ液
  • 大量の胸水の急速な排出で起こり得ること
    • 低血圧
    • 呼吸状態悪化
    • 再膨張性肺水腫
  • 指示で確認する排液の条件
    • 排液量
    • 速度
    • 中止条件

患者・指示・装置を一致させる

  • 処置の基本情報
    • 目的
    • 挿入側
    • 挿入部位
    • 挿入長の目印
  • 水封のみか持続吸引か、設定圧はいくつか
  • 排液の指示
    • 排液量の上限
    • 排液速度の上限
    • 中止基準
    • 報告基準
  • 場面ごとの扱い
    • クランプ
    • 移動
    • 離床
    • 検査
  • 挿入後・抜去後の画像確認と採血
  • 使用製品で確認
    • 水封水
    • 吸引表示
    • アラームの見方
処置直前に左右を声に出して確認
  • 照合する情報
    • 患者
    • 同意書
    • 画像
    • マーキング
    • 指示

    チームで挿入側を確認する。

  • 胸腔ドレーンには左右取り違えの医療事故報告がある。

呼吸性移動とエアリークの読み方

単独の所見では決めつけない

  • 呼吸性移動あり：胸腔内圧の変化が水封室へ伝わっている
  • 呼吸性移動がなくなる場合
    • 肺の再膨張後
    • 屈曲
    • 閉塞
    • クランプ
  • 咳で一時的な気泡：患者側のエアリークでみられることがある
  • 新しい持続性気泡：患者側または接続・装置側の漏れを疑う
新しい気泡や呼吸性移動消失を見たら
  • まず患者の呼吸状態を確認し、挿入部から装置まで目でたどる。
  • 閉塞箇所や接続の外れを探し、速やかに報告する。
  • 原因検索のためのクランプは、緊張性気胸を招く可能性があるため、訓練された者が明確な手順のもとで行う。

排液と皮下気腫

  • 量
    • 一定時間ごとの差と累積量を記録する。
    • 急増・急減・突然の停止を患者状態と合わせて評価する。
  • 色・性状の観察
    • 淡血性から漿液性への変化
    • 鮮血化
    • 混濁
    • 膿性
    • 乳白色
  • 突然の鮮血・増加：出血を疑い、バイタルサインと排液速度を確認して直ちに報告する。
  • 突然の停止時に確認
    • 屈曲
    • 圧迫
    • 凝血塊
    • 位置異常
    • 呼吸悪化

    排液停止は、改善とは限らない。

  • 皮下気腫を視診・触診する部位
    • 挿入部周囲
    • 胸部
    • 頸部
    合わせて確認する変化
    • 範囲の拡大
    • 声の変化
    • 呼吸困難
  • 皮下気腫の範囲を皮膚へ記す運用がある場合は、日時を添え、院内手順に従う。
  • 皮下気腫で緊急報告する変化
    • 頸部へ広がる
    • 急速に増える
    • 呼吸や発声に影響する

    いずれかがあれば緊急報告する。

体位・移動・日常生活

装置を倒さず、胸より低く保つ
  • 呼吸しやすい体位を整え、挿入側を下にするなど一律の体位に固定しない。
  • 体位変換ごとのチューブ確認
    • 牽引
    • 屈曲
    • 身体の下への巻き込み
  • 歩行時も装置を立てて胸より低く持ち、床へ直置きしない。
  • 移動前後の確認
    • 接続
    • 固定
    • 電源
    • 吸引
    • クランプの要否

    移動前に確認し、移動後も再確認する。

  • 咳嗽・深呼吸・離床は、疼痛を調整しながら患者の状態と指示に合わせる。

挿入介助

  1. 適応・同意・左右を確認する
    タイムアウト前の確認
    • 患者
    • 目的
    • 画像
    • 処置部位
    • 抗凝固薬
    • アレルギー
    • 検査値
    • 同意

    確認後にタイムアウトを行う。

  2. 監視と物品を準備する
    準備するもの
    • 酸素
    • 吸引
    • モニター
    • 救急物品
    • 局所麻酔
    • 無菌物品
    • ドレーン
    • 使用する排液装置
  3. 体位を整え無菌操作を介助する
    • 呼吸状態を連続観察し、疼痛と不安へ声をかける。
    • 胸水などでは超音波による部位確認を介助する。
  4. 接続・固定・作動を確認する
    無菌的に装置へ接続後、確認
    • 挿入長
    • 縫合
    • 固定
    • ドレッシング
    • 水封
    • 吸引設定
  5. 処置後を観察し記録する
    処置後の観察
    • 呼吸
    • 循環
    • 疼痛
    • 出血
    • 排液
    • エアリーク
    • 皮下気腫

    指示された胸部画像で位置を確認する。

抜去介助

  1. 抜去条件と指示を確認する
    抜去前の確認
    • 呼吸状態
    • 画像
    • 排液量
    • エアリーク
    • 抗凝固薬
    • 抜去後の画像・観察指示
  2. 患者へ説明し物品を準備する
    患者へ説明
    • 体位
    • 痛み
    • 呼吸の合図
    準備するもの
    • モニター
    • 被覆材
    • 抜糸・縫合物品
  3. 呼吸の合図を介助する
    • 息止めやバルサルバ法など、実施者が選んだ方法を患者と合わせる。
    • 吸気・呼気のどちらかを一律に覚えない。
  4. 抜去直後に密閉する
    • 実施者の抜去と同時に創部を速やかに閉鎖・被覆する。
    • 空気の流入と漏れを防ぐ。
  5. 呼吸状態と創部を再評価する
    抜去後の確認
    • 呼吸困難
    • SpO₂
    • 左右の呼吸音
    • 疼痛
    • 出血
    • 皮下気腫

    指示された画像と記録を行う。

胸腔穿刺と検体

検査目的と提出方法を先に確認する

  • 診断目的か治療目的か、採取する検査項目を確認
  • 患者と穿刺側を照合し、超音波による部位確認を介助
  • 治療的排液で確認する条件
    • 上限量
    • 速度
    • 中止症状
  • 検査項目に合う容器を検査部へ確認
    • 培養
    • 細胞診
    • 生化学
  • 採取後すぐに照合して提出
    • 患者情報
    • 検体
    • 時刻
  • 胸水へ一律にヘパリンを加えない。
  • 検査項目と施設の検査手順に従う事項
    • 添加剤
    • 採取量
    • 嫌気培養・血液培養ボトルの使用

すぐに応援を呼ぶ変化

患者を離れず、ABCDEで評価する

  • 呼吸悪化の徴候
    • 突然の強い呼吸困難
    • SpO₂低下
    • 胸痛
    • チアノーゼ
  • 循環・意識の変化
    • 血圧低下
    • 頻脈
    • 冷汗
    • 意識変化
  • 急な鮮血排液・排液増加、または症状を伴う排液停止
  • ドレーン・装置の異常
    • ドレーンの抜去
    • 接続外れ
    • 破損
    • 装置の転倒
  • 皮下気腫の急速な拡大、新しい持続性エアリーク
抜けた管を戻さない
  • 応援を要請し、患者の呼吸・循環を評価して酸素など必要な初期対応を行う。
  • 胸壁から抜けたドレーンは再挿入しない。
  • 創部と装置の扱いは院内の緊急手順に従い、再挿入に備える。
