  • 皮内注射

  • 筋肉内注射
  • 静脈内注射

  • 準備

学習用
優先する指示・手順
  • 薬剤の電子添文
  • 注射器の電子添文
  • 注射針の電子添文
  • 院内手順
  • 指導者の指示
  • 実際の手技では、上記の指示・手順を優先する。

注意事項

準備前
  • 指示と患者を照合
  • 指示で確認する項目
    • 薬剤名
    • 目的
    • 用量
    • 単位
    • 投与経路
    • 投与時刻
    • 投与速度
  • 患者のリスク確認
    • アレルギー歴
    • 副作用歴
    • 禁忌
    • 出血傾向
    • 抗血栓薬の使用
  • 電子添文で確認する項目
    • 希釈方法
    • 配合変化
    • 投与部位
    • 投与速度
    • 投与後の注意
  • 疑義があれば準備・投与を止めて確認
感染・誤投与の防止
  • 清潔な調製区域で無菌操作
  • 注射針と注射器は1患者・1回ごとに新品を使用
  • 使用済みの針・注射器でバイアルへ再穿刺しない
  • 単回使用のアンプル・バイアルの残液を他患者へ使用しない
  • 調製後の注射器に表示する項目の例
    • 患者名
    • 薬剤名
    • 用量
  • 使用直前の再確認
    • 患者
    • 薬剤
    • 用量
    • 経路
    • 時刻
穿刺・投与時
  • 安全機構付き器材を使用できる場合は選択
  • 直ちに中止する症状・異常
    • 疼痛
    • 電撃痛
    • しびれ
    • 強い抵抗
  • 注射針をリキャップしない
  • 使用後は手の届く位置にある耐貫通性容器へ直ちに廃棄
  • 投与後の揉み方・圧迫は薬剤ごとに確認。一律にマッサージしない
  • アナフィラキシーなどの急変へ対応できる体制で実施

目的

  • 薬剤を目的とする組織・血管内へ投与
  • 経口投与が難しい場合に薬剤を投与
  • 必要な作用発現時間や持続時間に合わせて投与経路を選択
  • 検査・治療に必要な薬剤を確実に投与

観察項目

  • 投与前後で比べる全身状態の例
    • 意識
    • 呼吸
    • 脈拍
    • 血圧
    • SpO₂
  • 過敏症などを疑う症状の観察
    • 発疹
    • 掻痒感
    • 顔面の腫脹
    • 口唇の腫脹
    • 喘鳴
    • 呼吸困難
  • 自覚症状・全身反応の観察
    • 悪心
    • 嘔吐
    • めまい
    • 冷汗
    • 気分不快
  • 穿刺部の観察
    • 疼痛
    • 発赤
    • 腫脹
    • 熱感
    • 硬結
    • 出血
  • 神経症状の観察
    • しびれ
    • 知覚異常
    • 運動障害
  • 薬剤の効果と予測される副作用
  • 静脈内投与で観察する異常
    • 注入抵抗
    • 漏れ
    • 静脈炎の徴候
    • 血管外漏出の徴候

注射の種類

  • 針先をどの層へ届けるかで、刺入角度と薬剤の吸収速度が変わる。
  • 模式図。
  • 皮下・筋肉内の角度はワクチン投与資料などに基づく一般値。
  • 薬剤専用デバイスや電子添文に指定がある場合は、その方法を優先する。

皮内注射

必要物品

  • 指示された薬剤
  • 1mL注射器または専用注射器
  • 指示に適合する注射針
  • 皮膚消毒薬
  • 手袋
  • 処置用シーツ
  • 耐貫通性廃棄容器
  • 廃棄物容器

手順

  1. 指示・患者・薬剤を確認
    皮内注射の事前確認
    • 目的
    • 投与量
    • 部位
    • 判定方法

    患者へ説明する。

  2. 薬剤を準備
    • 無菌操作で正確に調製。
    • 注射器内の気泡を除く。
  3. 部位を選択
    皮内注射で避ける局所状態
    • 発赤
    • 皮疹
    • 瘢痕
    • 浮腫
    • 感染
  4. 手指衛生・消毒
    • 手指衛生後に手袋を装着。
    • 皮膚を消毒し、乾燥させる。
  5. 刺入
    • 皮膚を張る。
    • ベベルを上に向け、5～15度で真皮内へ浅く刺入する。
  6. 薬剤を注入
    • 指示量を緩徐に注入。
    • 注入部の膨疹を確認する。
  7. 抜針・廃棄
    • 針を抜き、揉まない。
    • 針は直ちに耐貫通性容器へ廃棄する。
  8. 観察・記録
    皮内注射の記録
    • 部位
    • 薬剤
    • 投与量
    • 日時
    • 皮膚反応
    • 患者の状態

皮下注射

必要物品

  • 指示された薬剤
  • 薬剤に適合する注射器または専用注入器
  • 薬剤・体格に適合する注射針
  • 皮膚消毒薬
  • 手袋
  • 処置用シーツ
  • 耐貫通性廃棄容器
  • 廃棄物容器

手順

  1. 指示・患者・薬剤を確認
    皮下注射の事前確認
    • 投与部位
    • 前回部位
    • 薬剤別の注意

    患者へ説明する。

  2. 薬剤・器材を準備
    • 薬剤に適合する注射器と針を選ぶ。
    • 専用注入器は電子添文どおりに準備する。
  3. 部位を選択
    • 皮下注射の候補部位の例
      • 腹部
      • 上腕
      • 大腿
    • 皮下注射で避ける部位
      • 発赤
      • 硬結
      • 瘢痕
      • 浮腫
      • 感染
    • 反復投与では部位をローテーションする。
  4. 手指衛生・消毒
    • 手指衛生後に手袋を装着。
    • 皮膚を消毒し、乾燥させる。
  5. 刺入
    • 必要に応じて皮膚をつまむ。
    • 皮下組織へ刺入する。
    • 皮下注射の角度を調整する条件
      • 針長
      • 皮下脂肪厚
      • 器材の指示
  6. 薬剤を注入
    • 薬剤別の方法で注入。
    • 逆血確認の要否や注入後の待機時間は電子添文・院内手順に従う。
  7. 抜針・廃棄
    • 針を抜き、必要時は軽く圧迫。
    • マッサージの可否は薬剤ごとに確認する。
  8. 観察・記録
    皮下注射の記録
    • 部位
    • 薬剤
    • 投与量
    • 日時
    • 局所反応
    • 全身反応

筋肉内注射

必要物品

  • 指示された薬剤
  • 薬剤量に適合する注射器
  • 薬剤・部位・体格に適合する注射針
  • 皮膚消毒薬
  • 手袋
  • 処置用シーツ
  • 止血用ガーゼ
  • 耐貫通性廃棄容器
  • 廃棄物容器

手順

  1. 指示・患者・薬剤を確認
    筋肉内投与前の評価
    • 出血リスク
    • 投与量
    • 部位

    電子添文で筋肉内投与が可能か確認する。

  2. 薬剤を準備
    • 無菌操作で調製。
    • 薬剤の粘度と投与量を踏まえて針・注射器を選ぶ。
  3. 部位を選択
    筋肉内注射の部位選択で考慮する条件
    • 年齢
    • 筋肉量
    • 皮下脂肪厚
    • 神経の走行
    • 血管の走行
    • 薬剤量

    安全なランドマークを確認する。

  4. 体位を整える
    • 転倒や急な動きを防げる体位にする。
    • 対象筋を弛緩させる。
  5. 手指衛生・消毒
    • 手指衛生後に手袋を装着。
    • 皮膚を消毒し、乾燥させる。
  6. 刺入
    • 皮膚を安定させ、筋層へ90度で刺入。
    • 電撃痛やしびれがあれば直ちに中止する。
  7. 薬剤を注入
    吸引の要否を決める条件
    • 薬剤
    • 目的
    • 部位
    • 院内手順

    薬剤に定められた速度で注入する。

  8. 抜針・止血・廃棄
    • 針をまっすぐ抜き、必要に応じてガーゼで圧迫。
    • マッサージの可否は薬剤ごとに確認し、針は直ちに廃棄する。
  9. 観察・記録
    筋肉内注射の記録
    • 部位
    • 薬剤
    • 投与量
    • 針の規格
    • 日時
    • 局所反応
    • 全身反応

静脈内注射

  • ここでは、確保済みの末梢静脈路からの単回投与を扱う。
  • 静脈路の穿刺・固定は「末梢静脈路確保」を参照。

必要物品

  • 指示された薬剤
  • 薬剤量に適合する注射器
  • 指示された希釈液
  • 消毒用資材
  • 手袋
  • 生理食塩液入りシリンジ
  • 耐貫通性廃棄容器
  • 廃棄物容器

手順

  1. 指示・患者・薬剤を確認
    静脈内投与前の確認
    • 投与量
    • 希釈
    • 投与速度
    • 配合変化
    • 前後のフラッシュ
    • モニタリング
  2. 薬剤を準備
    • 清潔な調製区域で無菌的に調製。
    • 注射器へ必要事項を表示する。
  3. 静脈路を観察
    静脈路で確認する異常
    • 疼痛
    • 発赤
    • 腫脹
    • 漏れ
    • 静脈炎
    • 接続部の異常
  4. 投与経路を照合
    • 対象のルートと接続口を始点から患者側までたどる。
    • 同時投与薬との配合変化を確認する。
  5. 手指衛生・接続口の消毒
    • 手指衛生後に手袋を装着。
    • 接続口を院内手順どおりに消毒し、乾燥させる。
  6. 開通性を確認
    開通性確認で投与を行わない異常
    • 疼痛
    • 腫脹
    • 漏れ
    • 抵抗

    院内手順に沿って確認する。

  7. 薬剤を投与
    • 定められた速度で投与。
    • 患者と穿刺部を観察する。
    • 抵抗時は押し込まない。
  8. 投与後の処置
    • 薬剤と院内手順に従ってフラッシュ。
    • 接続部を確実に閉鎖する。
  9. 観察・記録
    静脈内注射の記録
    • 薬剤
    • 投与量
    • 経路
    • 速度
    • 日時
    • 穿刺部
    • 患者の反応

関連知識

代表的な刺入部位

  • 成人の代表的な候補部位を簡略化した模式図。
  • 実際の部位選択で確認する条件
    • 薬剤
    • 年齢
    • 体格
    • 組織の厚さ
    • 神経の走行
    • 血管の走行

投与部位を選ぶ視点

  • 薬剤で承認された投与経路・投与部位
  • 部位選択で確認する身体条件
    • 年齢
    • 体格
    • 筋肉量
    • 皮下脂肪厚
  • 部位選択で確認する位置関係
    • 神経
    • 血管
    • 骨
  • 部位選択で確認する局所状態
    • 発赤
    • 硬結
    • 瘢痕
    • 浮腫
    • 感染
  • 前回の穿刺部位と局所反応
  • 部位選択で確認する既往・状態の例
    • 手術歴
    • リンパ節郭清
    • 麻痺
    • シャント

逆血確認は一律ではない

  • 逆血確認の要否が異なる条件
    • 投与経路
    • 薬剤
    • 部位
    • 目的
  • 推奨部位へのワクチン筋肉内・皮下注射では、一般に吸引は不要
  • ワクチン以外へ同じ判断を一律に当てはめない
  • 逆血確認の要否を確認する資料
    • 電子添文
    • 最新ガイドライン
    • 院内手順

主な有害事象・合併症

アナフィラキシー
アナフィラキシーを疑う症状の例
  • 皮膚症状
  • 呼吸器症状
  • 血圧低下
  • 消化器症状

疑えば直ちに応援要請と緊急対応を行う。

血管迷走神経反射
血管迷走神経反射の症状の例
  • 顔面蒼白
  • 冷汗
  • 悪心
  • 徐脈
  • 血圧低下
  • 失神

転倒を防ぎ、状態を評価する。

神経損傷
神経損傷を疑う症状の例
  • 電撃痛
  • しびれ
  • 知覚障害
  • 運動障害

症状時は直ちに中止する。

出血・血腫
出血・血腫の症状の例
  • 皮下出血
  • 腫脹
  • 持続出血

出血リスクを事前評価し、確実に圧迫する。

感染・膿瘍
感染・膿瘍の症状の例
  • 発赤
  • 熱感
  • 疼痛
  • 腫脹
  • 排膿
  • 発熱

無菌操作と適切な部位選択が重要。

局所反応
局所反応の症状の例
  • 疼痛
  • 発赤
  • 腫脹
  • 硬結

薬剤特性と経過を踏まえて評価する。

血管外漏出
  • 静脈内投与薬が血管外へ漏出。
  • 投与を止め、薬剤別手順で対応。
針刺し損傷
  • リキャップや廃棄時に発生しうる。
  • 発生時は洗浄し、院内の曝露後手順へ直ちに従う。
