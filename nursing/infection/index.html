基本の感染対策

感染経路を想像し、手指衛生・個人防護具・環境整備を組み合わせるための学習ノート。

このページは、新人看護師が学んだ内容を自分なりに整理した学習記録。実際のケアや判断では、患者の状態、所属施設のマニュアル、感染管理担当者の指示を優先する。

標準予防策と感染経路別予防策

必要な場合に追加する感染経路別予防策
  • 接触
  • 飛沫
  • 空気
すべての患者・すべてのケアの土台標準予防策

標準予防策は、感染症が判明している患者だけに行うものではない。血液・体液などを感染の可能性があるものとして扱い、ケアの内容と曝露の可能性に応じて対策を選ぶ。

接触感染

患者や周囲の物品に触れて運ばれる

代表的な例

  • MRSAなどの薬剤耐性菌
  • ノロウイルス感染症
  • クロストリディオイデス・ディフィシル感染症
  • 疥癬

主な対策手指衛生、手袋・ガウン、患者周囲の環境整備

飛沫感染

咳や会話などのしぶきで届く

代表的な例

  • インフルエンザ
  • 百日咳
  • 流行性耳下腺炎・風疹
  • 髄膜炎菌感染症

主な対策サージカルマスク、必要に応じた目の防護、患者配置

空気感染

細かな粒子が空気中を漂う

代表的な例

  • 肺結核・喉頭結核
  • 麻疹
  • 水痘
  • 播種性帯状疱疹

主な対策N95等の呼吸用防護具、適切な換気・病室管理

感染経路別予防策は、標準予防策の代わりではなく追加して行う。診断確定前でも感染症が疑われる段階から開始する場合がある。水痘・播種性帯状疱疹では空気予防策と接触予防策を併用するなど、複数の経路へ対策が必要な感染症もある。適用・解除は施設の手順を確認する。

手指衛生

流水と石けん

目に見える汚れがある

  • 血液・体液などで汚れている
  • トイレのあと
  • 施設が流水手洗いを指定する場面

汚れと微生物を洗い流す

アルコール擦式消毒

目に見える汚れがない

  • 多くの臨床場面で第一選択
  • 必要量を手全体に広げる
  • 乾くまで擦り込む

短時間で多くの微生物を減らす

方法を変える場面

集団発生時や芽胞をつくる微生物などでは対応が変わることがある。施設の感染対策手順を確認する。

見落としやすい場所

  • 指先・爪
  • 親指
  • 指の間
  • 手の甲
  • 手首

手指衛生の5つのタイミング

  1. 患者に触れる前
  2. 清潔・無菌操作の前
  3. 体液に曝露した可能性のあと
  4. 患者に触れたあと
  5. 患者周囲に触れたあと

個人防護具

予想される曝露から選ぶ
  • 手に触れる可能性がある：手袋
  • 衣服や皮膚が汚染される可能性がある：ガウン
  • 鼻や口へ飛散する可能性がある：マスク・呼吸用防護具
  • 目へ飛散する可能性がある：ゴーグル・フェイスシールド

着ける順番

  1. 手指衛生
  2. ガウン
  3. マスク・N95等
  4. 目の防護
  5. 手袋

外す順番

  1. 手袋
  2. ガウン
  3. 手指衛生
  4. 目の防護
  5. マスク・N95等
  6. 手指衛生

外側は汚染している前提で、手袋の外側やガウンの前面・袖に素手で触れない。外す順番や場所は、防護具の種類と施設手順によって異なる。

感染性廃棄物の分類

感染性廃棄物は、形状に合う容器へ使用場所で分ける。以下は環境省マニュアルのバイオハザード表示色。実際の容器と分別は施設の表示を確認する。

☣︎赤

液状・泥状

血液など、液状または泥状のもの

☣︎橙

固形状

血液が付着したガーゼなど

☣︎黄

鋭利なもの

注射針など、貫通のおそれがあるもの

  • 使用場所ですぐ廃棄持ち歩く距離を増やさない
  • 押し込まない満杯になる前に容器を交換
  • 迷ったら確認施設の分別表を確認
